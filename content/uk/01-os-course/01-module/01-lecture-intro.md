## Що таке операційна система

Операційна система (ОС) — це комплекс програм, що забезпечує керування апаратним забезпеченням комп'ютера, організовує роботу з файлами та виконання прикладних програм, здійснює введення та виведення даних.

Операційна система виконує роль посередника між користувачем і комп'ютером. Вона приховує складність апаратного забезпечення та надає зручний інтерфейс для роботи.

Основні функції операційної системи:

- **Керування процесами** — створення, планування та завершення процесів
- **Керування пам'яттю** — розподіл оперативної пам'яті між процесами
- **Керування файловою системою** — організація зберігання даних
- **Керування пристроями** — взаємодія з периферійним обладнанням
- **Забезпечення безпеки** — контроль доступу до ресурсів системи

## Коротка історія

Історія операційних систем тісно пов'язана з розвитком комп'ютерної техніки.

**1950-ті роки** — перші комп'ютери працювали без операційних систем. Програмісти взаємодіяли безпосередньо з апаратним забезпеченням.

**1960-ті роки** — з'явилися перші пакетні операційні системи. Вони дозволяли автоматично виконувати послідовність завдань без участі оператора.

**1970-ті роки** — створення UNIX в лабораторіях Bell Labs. Ця система заклала основи багатьох сучасних концепцій:

- Ієрархічна файлова система
- Командний інтерпретатор (shell)
- Принцип "все є файлом"

> «UNIX is basically a simple operating system, but you have to be a genius to understand the simplicity.»
>
> — Dennis Ritchie, співавтор UNIX

**1980-ті роки** — ера персональних комп'ютерів. MS-DOS та перші версії Windows зробили комп'ютери доступними для масового користувача.

**1990-ті роки** — Windows 95 принесла графічний інтерфейс у кожен дім. Паралельно розвивався Linux — вільна операційна система на базі ідей UNIX.

**2000-ні та далі** — мобільні операційні системи (Android, iOS), хмарні технології, контейнеризація.

## Перше знайомство з інтерфейсом ОС

Кожна операційна система надає інтерфейс для взаємодії з користувачем. Найпоширеніші типи інтерфейсів:

1. **Командний рядок (CLI)** — текстовий інтерфейс, де користувач вводить команди
2. **Графічний інтерфейс (GUI)** — візуальний інтерфейс з вікнами, іконками, меню

Розглянемо базові команди для перегляду вмісту каталогу:

```bash
# Windows (Command Prompt)
dir

# Linux / macOS
ls -la
```

Результат виконання команди `ls -la` у Linux:

```
total 32
drwxr-xr-x  5 user user 4096 Jan 15 10:30 .
drwxr-xr-x  3 user user 4096 Jan 14 09:15 ..
-rw-r--r--  1 user user  220 Jan 14 09:15 .bashrc
drwxr-xr-x  2 user user 4096 Jan 15 10:25 Documents
drwxr-xr-x  2 user user 4096 Jan 15 10:30 Downloads
-rw-r--r--  1 user user  807 Jan 14 09:15 README.md
```

Цей вивід показує:

- Права доступу до файлів (`drwxr-xr-x`)
- Власника та групу (`user user`)
- Розмір файлу в байтах
- Дату останньої модифікації
- Назву файлу або каталогу
