## Теоретичні відомості

### 1 Пакетний файл і командний процесор

Пакетний (командний) файл — це звичайний текстовий файл з розширенням `.bat` або `.cmd`, кожен рядок якого командний процесор `cmd.exe` виконує так, ніби користувач ввів його з клавіатури. Жодного компілятора не потрібно: інтерпретатором є сама оболонка, яка вже входить до складу системи.

З погляду операційної системи запуск пакетного файлу — це створення процесу `cmd.exe`, якому передано ім'я сценарію. Усі команди всередині виконуються в цьому процесі, а зовнішні утиліти (`robocopy`, `ping`, `tasklist`) породжують власні дочірні процеси. Тому змінна, встановлена всередині скрипта, за замовчуванням зникає разом із його процесом і не впливає на батьківське вікно.

Розширення `.cmd` з'явилося в лінійці Windows NT і відрізняється від `.bat` дрібницями в обробці кодів повернення. Для навчальних задач вони взаємозамінні; далі використовується `.bat`.

### 2 Структура файлу, ехо та коментарі

Перший рядок майже кожного сценарію — `@echo off`. Команда `echo off` вимикає дублювання команд на екран, а символ `@` приховує саму цю команду. Без неї вікно засмічується текстом сценарію, і знайти в ньому результат роботи стає важко.

```cmd
@echo off
rem Резервне копіювання документів
chcp 65001 > nul
setlocal

echo Початок роботи: %date% %time%
:: Подвійна двокрапка теж працює як коментар
endlocal
```

Команда `chcp 65001` перемикає кодову сторінку консолі на UTF-8 — без неї українські літери у виводі перетворюються на «кракозябри». Пара `setlocal` / `endlocal` обмежує область дії змінних: усе, що встановлено між ними, після завершення скрипта зникає.

Коментують рядки командою `rem` або скороченням `::`. Форма `::` не є командою: це помилкова мітка, яку процесор мовчки пропускає, тому всередині блоків `for` і дужок `( )` її застосовувати не можна — там припустимий лише `rem`.

### 3 Змінні та параметри командного рядка

Змінна створюється командою `set` і розгортається у відсотках. Пробіли навколо знака рівності стають частиною імені або значення, тому їх не ставлять.

```cmd
set name=LAB3
set "path_to_log=%USERPROFILE%\Desktop\LAB3\log.txt"
echo Каталог: %name%
```

Аргументи, передані скрипту під час запуску, доступні як `%1`...`%9`, ім'я самого скрипта — `%0`. Команда `shift` зсуває аргументи на одну позицію, що дозволяє обробити їх довільну кількість.

Особливо корисні модифікатори параметрів: вони дістають із шляху окремі складові.

Таблиця 1 — Модифікатори параметрів пакетного файлу

| Запис | Що повертає | Приклад результату |
|-------|-------------|--------------------|
| `%~1` | значення без лапок | `C:\Data\report.txt` |
| `%~n1` | тільки ім'я файлу | `report` |
| `%~x1` | тільки розширення | `.txt` |
| `%~d1` | літеру диска | `C:` |
| `%~p1` | шлях без диска й імені | `\Data\` |
| `%~dp0` | каталог самого скрипта | `C:\Users\Student\Desktop\LAB3\` |
| `%~z1` | розмір файлу в байтах | `1024` |
| `%~t1` | дату й час зміни | `17.09.2026 22:15` |

Запис `%~dp0` — найважливіший із них: він дозволяє скрипту працювати відносно власного розташування, а не поточного каталогу, з якого його запустили.

### 4 Арифметика

Командний процесор оперує рядками, тому для обчислень потрібен ключ `/a`. Він вмикає цілочислову арифметику: додавання, віднімання, множення, ділення з відкиданням дробової частини та остачу.

```cmd
set /a total = 7 + 5
set /a half = total / 2
set /a rest = total %% 2
set /a counter += 1
```

Дробових чисел командний процесор не підтримує взагалі — для них доводиться або множити на 100 і рахувати в сотих, або переходити на PowerShell.

### 5 Умовні оператори

Команда `if` має три основні форми: порівняння значень, перевірка існування файлу та перевірка коду повернення попередньої команди.

Таблиця 2 — Форми умовного оператора

| Форма | Призначення |
|-------|-------------|
| `if "%1"=="" (...)` | перевірка, чи переданий аргумент |
| `if /i "%mode%"=="full" (...)` | порівняння без урахування регістру |
| `if exist "%file%" (...)` | перевірка наявності файлу або каталогу |
| `if not exist "%dir%" md "%dir%"` | створення каталогу, якщо його немає |
| `if errorlevel 1 (...)` | попередня команда завершилася з помилкою |
| `if %count% gtr 10 (...)` | числове порівняння: gtr, geq, lss, leq, equ, neq |

Значення беруть у лапки не для краси: якщо змінна порожня, запис `if %mode%==full` перетворюється на синтаксично хибний рядок `if ==full`, і скрипт аварійно зупиняється. Лапки роблять порівняння коректним за будь-якого значення.

Умова `if errorlevel 1` істинна, коли код повернення **більший або рівний** одиниці. Саме тому перевірки записують від більшого коду до меншого, а не навпаки.

### 6 Цикли

Цикл `for` у пакетних файлах має кілька різновидів, які відрізняються ключем. Змінна циклу в скрипті записується двома відсотками (`%%i`), у командному рядку — одним (`%i`).

```cmd
for %%f in (*.txt) do echo %%~nf
for /r %%f in (*.log) do echo %%f
for /d %%d in (*) do echo Каталог: %%d
for /l %%n in (1,1,10) do echo Крок %%n
for /f "tokens=1,3 delims=;" %%a in (data.csv) do echo %%a - %%b
for /f "skip=1 tokens=*" %%s in ('tasklist') do echo %%s
```

Ключ `/f` — найпотужніший: він читає рядки з файлу, з тексту або з виводу іншої команди (якщо джерело взяти в одинарні лапки) і розбиває їх на поля. Опція `tokens` вказує, які поля взяти, `delims` — якими символами вони розділені, `skip` — скільки рядків заголовка пропустити.

### 7 Мітки, переходи та підпрограми

Мітка — рядок, що починається з двокрапки. Команда `goto` передає керування на мітку, а `call :мітка` викликає ділянку коду як підпрограму: після команди `goto :eof` виконання повертається в точку виклику.

```cmd
@echo off
if "%1"=="" goto :usage

call :log Початок обробки
call :process "%1"
call :log Завершено
goto :eof

:process
echo Обробляю %~1
goto :eof

:log
echo [%time%] %* >> "%~dp0log.txt"
goto :eof

:usage
echo Використання: %~n0 ^<каталог^>
exit /b 1
```

Псевдомітка `:eof` (end of file) вбудована в процесор — оголошувати її не потрібно. Команда `exit /b N` завершує скрипт із заданим кодом повернення, який батьківський процес може перевірити через `errorlevel`.

### 8 Відкладене розгортання змінних

Усередині блоку в дужках командний процесор підставляє значення змінних **до** початку виконання блоку. Тому класична помилка-новачка виглядає так: лічильник у циклі не змінюється.

```cmd
set count=0
for %%f in (*.txt) do set /a count += 1
echo Файлів: %count%
```

Розв'язок — режим відкладеного розгортання: після `setlocal enabledelayedexpansion` звертання виду `!count!` обчислюється в момент виконання рядка, а не під час розбору блоку.

```cmd
@echo off
setlocal enabledelayedexpansion
set count=0
for %%f in (*.txt) do (
    set /a count += 1
    echo !count!: %%~nxf
)
echo Усього файлів: !count!
endlocal
```

### 9 Коди повернення та журнал

Зовнішні утиліти повідомляють про результат кодом повернення. Нуль традиційно означає успіх, ненульове значення — конкретну помилку; для `robocopy` навіть код 1 є ознакою успішного копіювання.

```cmd
robocopy "%src%" "%dst%" /e /njh /njs
if %errorlevel% geq 8 (
    echo ПОМИЛКА копіювання, код %errorlevel% >> "%log%"
    exit /b %errorlevel%
)
```

Журнал виконання ведуть перенаправленням `>>` — воно дописує рядок у кінець файлу. Записувати варто час, дію та результат: саме за журналом розбирають, чому скрипт, який працює вручну, «мовчки» не спрацював за розкладом.

## Приклад виконання

Нижче наведено послідовність дій для довільної системи. Конкретні шляхи й перелік файлів на вашій машині будуть іншими — у звіт вносяться саме ваші результати.

### Крок 1. Пісочниця та перший скрипт

```cmd
C:\Users\Student> cd %USERPROFILE%\Desktop
C:\Users\Student\Desktop> md LAB3\src LAB3\bak LAB3\logs
C:\Users\Student\Desktop> cd LAB3
C:\...\LAB3> copy %SystemRoot%\System32\drivers\etc\hosts src\hosts.txt
        1 file(s) copied.
C:\...\LAB3> notepad hello.bat
```

Вміст `hello.bat`:

```cmd
@echo off
chcp 65001 > nul
echo Скрипт: %~n0
echo Каталог скрипта: %~dp0
echo Поточний каталог: %cd%
echo Користувач: %USERNAME%
pause
```

```cmd
C:\...\LAB3> hello.bat
Скрипт: hello
Каталог скрипта: C:\Users\Student\Desktop\LAB3\
Поточний каталог: C:\Users\Student\Desktop\LAB3
Користувач: Student
Press any key to continue . . .
```

Різниця між `%~dp0` і `%cd%` стає очевидною, якщо запустити той самий скрипт із іншого каталогу: перше значення не змінюється, друге — змінюється.

### Крок 2. Параметри та перевірка вхідних даних

```cmd
@echo off
chcp 65001 > nul
if "%~1"=="" (
    echo Використання: %~n0 ^<файл^>
    exit /b 1
)
if not exist "%~1" (
    echo Файл "%~1" не знайдено
    exit /b 2
)
echo Ім'я:        %~n1
echo Розширення:  %~x1
echo Розмір:      %~z1 байт
echo Змінено:     %~t1
exit /b 0
```

```cmd
C:\...\LAB3> info.bat
Використання: info ^<файл^>
C:\...\LAB3> echo %errorlevel%
1

C:\...\LAB3> info.bat src\hosts.txt
Ім'я:        hosts
Розширення:  .txt
Розмір:      824 байт
Змінено:     17.09.2026 21:40
C:\...\LAB3> echo %errorlevel%
0
```

Скрипт повертає різні коди для різних причин відмови — саме так сценарій вбудовують у більший ланцюжок автоматизації.

### Крок 3. Цикл по файлах і лічильник

```cmd
@echo off
chcp 65001 > nul
setlocal enabledelayedexpansion
set count=0
set /a bytes = 0

for %%f in ("%~dp0src\*.*") do (
    set /a count += 1
    set /a bytes += %%~zf
    echo !count!^) %%~nxf — %%~zf байт
)

echo Файлів: !count!, загальний обсяг: !bytes! байт
endlocal
```

```cmd
C:\...\LAB3> count.bat
1) hosts.txt — 824 байт
2) readme.txt — 132 байт
Файлів: 2, загальний обсяг: 956 байт
```

Якщо прибрати `enabledelayedexpansion` і замінити `!count!` на `%count%`, вивід покаже нулі: значення підставиться один раз до початку циклу.

### Крок 4. Резервне копіювання з журналом

```cmd
@echo off
chcp 65001 > nul
setlocal
set "src=%~dp0src"
set "dst=%~dp0bak\%date:~6,4%-%date:~3,2%-%date:~0,2%"
set "log=%~dp0logs\backup.log"

call :log Джерело: "%src%"
if not exist "%dst%" md "%dst%"

robocopy "%src%" "%dst%" /e /njh /njs /ndl >> "%log%"
if %errorlevel% geq 8 (
    call :log ПОМИЛКА robocopy, код %errorlevel%
    endlocal
    exit /b %errorlevel%
)

call :log Призначення: "%dst%"
endlocal
exit /b 0

:log
echo [%date% %time%] %* >> "%~dp0logs\backup.log"
goto :eof
```

```cmd
C:\...\LAB3> backup.bat
C:\...\LAB3> type logs\backup.log
[17.09.2026 22:03:11,45] Джерело: "C:\Users\Student\Desktop\LAB3\src"
[17.09.2026 22:03:11,63] Призначення: "C:\Users\Student\Desktop\LAB3\bak\2026-09-17"
```

Підстановка виду `%date:~6,4%` вирізає з рядка дати чотири символи, починаючи з сьомого, — так формують ім'я каталогу, що сортується за зростанням.

Важливо: `%date%` повертає дату у форматі поточної локалі, тому ці зсуви правильні
для українського й російського форматів (`17.09.2026`), але для англійської локалі
(`09/17/2026` або `Thu 09/17/2026`) дадуть інший результат. Якщо скрипт має працювати
на будь-якій системі, дату беруть у незалежному від локалі вигляді:

```cmd
set "fmt=Get-Date -Format yyyy-MM-dd"
for /f %%i in ('powershell -NoProfile -Command "%fmt%"') do set "stamp=%%i"
set "dst=%~dp0bak\%stamp%"
```

### Крок 5. Читання файлу та розбір рядків

```cmd
@echo off
chcp 65001 > nul
for /f "usebackq skip=1 tokens=1,2 delims=;" %%a in ("%~dp0src\users.csv") do (
    echo Користувач %%a працює у відділі %%b
)
```

```cmd
C:\...\LAB3> type src\users.csv
name;department
ivanov;IT
petrenko;Accounting

C:\...\LAB3> parse.bat
Користувач ivanov працює у відділі IT
Користувач petrenko працює у відділі Accounting
```

Опція `usebackq` дозволяє взяти ім'я файлу в лапки — без неї шлях із пробілами розібрати не вдасться.

### Крок 6. Перевірка перед видаленням

```cmd
@echo off
chcp 65001 > nul
set "target=%~dp0bak"
echo Буде видалено:
for /r "%target%" %%f in (*.tmp) do echo   %%f

choice /c yn /m "Продовжити видалення"
if errorlevel 2 (
    echo Скасовано користувачем
    exit /b 0
)
for /r "%target%" %%f in (*.tmp) do del "%%f"
echo Готово
```

Команда `choice` повертає код 1 для «y» і 2 для «n», тому перевірку роблять від більшого коду. Режим попереднього перегляду — обов'язкова частина будь-якого сценарію, що видаляє дані.

## Порядок виконання роботи

1. Отримати в викладача номер індивідуального варіанта.

2. Створити на робочому столі каталог LAB3 з підкаталогами src, bak і logs. Наповнити src принаймні п'ятьма файлами різних типів, зокрема одним текстовим файлом з даними у стовпцях.

3. Написати скрипт `info.bat`, який приймає ім'я файлу параметром, перевіряє його існування і виводить ім'я, розширення, розмір та дату зміни. Передбачити коди повернення для випадків «параметр не переданий» і «файл не знайдено». Перевірити обидва випадки й зафіксувати значення `errorlevel`.

4. Написати скрипт, який обходить каталог src циклом `for`, рахує кількість файлів і сумарний обсяг та виводить нумерований перелік. Використати відкладене розгортання змінних.

5. Повторити попередній пункт без `enabledelayedexpansion` і пояснити у звіті, чому лічильник поводиться інакше.

6. Реалізувати основний скрипт свого варіанта згідно з таблицею. Скрипт має: приймати параметр, перевіряти вхідні дані, виконувати корисну дію в циклі та записувати журнал у logs.

7. Винести повторюване записування журналу в підпрограму, яку викликати через `call :log`.

8. Додати до скрипта перевірку коду повернення зовнішньої утиліти (`robocopy`, `xcopy` або `find`) і окреме повідомлення про помилку в журналі.

9. Запустити скрипт двічі: з коректними даними і з навмисно хибними. Зафіксувати вміст журналу в обох випадках.

10. Виконати додаткове завдання свого варіанта.

11. Оформити звіт і зробити висновок.

## Вимоги до звіту

Звіт оформлюється на бланку встановленого зразка і має містити:

- тему, мету та обладнання;
- постановку задачі за індивідуальним варіантом;
- повний текст усіх написаних скриптів із коментарями;
- таблицю використаних команд і ключів із поясненням призначення кожного;
- знімки екрана з результатами запуску, зокрема для випадку хибних вхідних даних;
- вміст журналу logs після обох запусків;
- пояснення різниці між `%count%` і `!count!` за результатами пункту 5;
- відповідь на запитання додаткового завдання варіанта;
- висновок про те, які задачі доцільно автоматизувати пакетними файлами, а коли потрібен PowerShell.

## Контрольні запитання

Запитання згруповано за рівнями навчальних досягнень. Для позитивної оцінки студент має відповісти на запитання середнього рівня, оцінка «добре» потребує відповідей достатнього рівня, оцінка «відмінно» — високого.

### Середній рівень (репродуктивний)

1. Що таке пакетний файл і який процес його виконує?
2. Для чого на початку скрипта пишуть `@echo off` і що робить символ `@`?
3. Якими двома способами записують коментарі в batch-файлі?
4. Як звернутися до першого та другого аргументів командного рядка?
5. Що повертають модифікатори `%~n1`, `%~x1` і `%~dp0`?
6. Яким ключем команди `set` вмикають арифметику?
7. Назвіть три форми оператора `if`.
8. Чим змінна циклу `%%i` у скрипті відрізняється від `%i` у командному рядку?

### Достатній рівень (конструктивно-варіативний)

1. Запишіть команду, яка виведе імена всіх файлів `.log` у поточному каталозі та всіх його підкаталогах.
2. Чому значення в умові беруть у лапки: `if "%mode%"=="full"`? Що станеться без них, якщо змінна порожня?
3. Що означає `if errorlevel 1` і чому перевірки кодів записують від більшого до меншого?
4. Побудуйте цикл `for /f`, який прочитає перший і третій стовпці файлу з роздільником «крапка з комою».
5. Чим `call :мітка` відрізняється від `goto :мітка`?
6. Для чого потрібні `setlocal` і `endlocal`? Що станеться зі змінними після завершення скрипта без них?
7. Запишіть рядок, який дописує в журнал поточний час і текст повідомлення.
8. Чим `exit /b 1` відрізняється від `exit 1` під час запуску скрипта з відкритого вікна cmd?

### Високий рівень (творчий)

1. Лічильник у циклі `for` завжди дорівнює нулю після завершення. Поясніть причину через порядок розбору блоку й запропонуйте два різні способи виправлення.
2. Потрібно щоночі копіювати робочий каталог, зберігати п'ять останніх копій і видаляти старіші. Опишіть структуру скрипта: які перевірки, який цикл, які коди повернення.
3. Скрипт працює, коли його запускають подвійним клацанням, і не працює, коли він викликається з планувальника завдань. Назвіть щонайменше три ймовірні причини й спосіб перевірки кожної.
4. Сформулюйте критерій, за яким задачу варто розв'язувати пакетним файлом, а коли переходити на PowerShell. Обґрунтуйте прикладом із цієї роботи.
