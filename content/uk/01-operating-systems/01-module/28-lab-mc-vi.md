**Мета:** опанувати роботу в текстовому режимі без графічного середовища: навчитися виконувати файлові операції у двопанельному менеджері Midnight Commander, користуватися його вбудованими переглядачем і редактором, а також редагувати файли в редакторі vi — перемикати режими, переміщатися текстом, виконувати пошук і заміну, зберігати зміни.

## Теоретичні відомості

### 1 Чому текстовий режим досі потрібен

Сервер зазвичай не має графічного середовища: воно споживає ресурси й збільшує поверхню атаки. Адміністратор під'єднується до такої машини через SSH і бачить лише текстовий термінал. Те саме стосується аварійних ситуацій: якщо графічна оболонка не стартує, залишається консоль TTY, у якій працюють `mc` і `vi`.

Редактор `vi` присутній практично в кожній Unix-системі — від мінімального контейнера до вбудованого пристрою. Саме тому навичка виходу з `vi` та збереження файлу вважається базовою для адміністратора.

### 2 Інтерфейс Midnight Commander

Midnight Commander — двопанельний файловий менеджер у текстовому режимі. Ліва й права панелі показують різні каталоги, активна панель позначена підсвіченим рядком. Унизу — рядок функціональних клавіш, угорі — меню, доступне клавішею F9.

Таблиця 1 — Основні клавіші Midnight Commander

| Клавіші | Дія |
|---------|-----|
| `Tab` | перемкнути активну панель |
| `Enter` | увійти в каталог або запустити файл |
| `F3` | переглянути файл (без можливості змінити) |
| `F4` | редагувати файл вбудованим редактором |
| `F5` | копіювати на протилежну панель |
| `F6` | перемістити або перейменувати |
| `F7` | створити каталог |
| `F8` | видалити (без підтвердження повернення) |
| `F9` | меню, `F10` — вихід |
| `Insert` | позначити файл для групової операції |
| `Ctrl+O` | сховати панелі й показати консоль |
| `Alt+Shift+H` | історія переходів між каталогами |
| `Ctrl+\` | список закладок каталогів |

Панель mc показує не лише імена: у режимі «Довгий» (меню панелі) видно розмір, права й час зміни, а поле «Швидкий перегляд» на другій панелі дозволяє бачити вміст файлу під час переміщення курсором.

### 3 Операції з групами файлів у mc

Клавіша `Insert` позначає файли, `+` і `-` відкривають діалог позначення за маскою. Позначені файли обробляються однією операцією: F5 скопіює всі, F8 видалить усі. Це основний спосіб масових дій у текстовому режимі.

Корисні можливості меню F9: порівняння каталогів (Команда → Порівняти каталоги), пошук файлів (Команда → Пошук файлу), а також панель із деревом каталогів для швидкої навігації.

### 4 Три режими редактора vi

Головна відмінність `vi` від звичних редакторів — модальність. Те, що робить клавіша, залежить від поточного режиму.

Таблиця 2 — Режими редактора vi

| Режим | Призначення | Як увійти | Як вийти |
|-------|-------------|-----------|----------|
| Командний | переміщення, видалення, копіювання | стан за замовчуванням | — |
| Вставки | введення тексту | `i`, `a`, `o`, `I`, `A`, `O` | `Esc` |
| Останнього рядка | збереження, вихід, заміна | `:` з командного | `Enter` або `Esc` |

Класична помилка новачка — набирати текст одразу після запуску: у командному режимі літери сприймаються як команди. Правило просте: сумніваєшся — натисни `Esc`, це завжди повертає в командний режим.

### 5 Переміщення й редагування

```
h j k l        ліворуч, вниз, вгору, праворуч
0  $           початок і кінець рядка
w  b           наступне й попереднє слово
gg  G          початок і кінець файлу
:25            перейти до рядка 25
Ctrl+f Ctrl+b  сторінка вперед і назад
```

```
x              видалити символ під курсором
dd             видалити рядок
3dd            видалити три рядки
dw             видалити слово
yy             скопіювати рядок
p              вставити після курсора
u              скасувати останню дію
Ctrl+r         повторити скасовану дію
.              повторити останню команду
```

Команди `vi` комбінуються за схемою «кількість + дія + об'єкт»: `3dw` видалить три слова, `2yy` скопіює два рядки. Саме ця комбінаторика робить редактор швидким після засвоєння базових команд.

### 6 Збереження, вихід, пошук і заміна

Таблиця 3 — Команди останнього рядка

| Команда | Дія |
|---------|-----|
| `:w` | зберегти |
| `:w ім'я` | зберегти під іншим іменем |
| `:q` | вийти (якщо змін немає) |
| `:wq` або `ZZ` | зберегти й вийти |
| `:q!` | вийти без збереження |
| `:set number` | показати номери рядків |
| `/текст` | пошук уперед, `n` — наступне збігання |
| `?текст` | пошук назад |
| `:%s/старе/нове/g` | замінити в усьому файлі |
| `:%s/старе/нове/gc` | замінити з підтвердженням кожного випадку |

Якщо файл відкрито без прав на запис, `:w` завершиться помилкою. Для системних файлів застосовують `sudo vi` або, вже перебуваючи в редакторі, команду `:w !sudo tee %`.

## Приклад виконання

### Крок 1. Підготовка й запуск mc

```bash
student@lab-vm:~$ sudo apt install -y mc vim
student@lab-vm:~$ mkdir -p ~/lab9/{conf,bak}
student@lab-vm:~$ cp /etc/ssh/sshd_config /etc/fstab /etc/hosts ~/lab9/conf/
student@lab-vm:~$ cd ~/lab9 && mc
```

Після запуску mc ліва панель показує `~/lab9`, права — домашній каталог. Клавіша `Tab` перемикає активну панель, `Ctrl+O` тимчасово ховає панелі й повертає звичайну консоль.

### Крок 2. Файлові операції в mc

```
1. Tab            → перейти на праву панель
2. Enter на lab9  → відкрити робочий каталог
3. Tab, Enter на conf
4. Insert         → позначити hosts і fstab (два файли)
5. F5             → копіювати на протилежну панель (bak)
6. F6 на sshd_config → перейменувати на sshd_config.orig
7. F7             → створити каталог tmp
8. F3 на hosts    → переглянути вміст, вихід — F10
```

```bash
student@lab-vm:~/lab9$ ls -R
.:
bak  conf

./bak:
fstab  hosts

./conf:
fstab  hosts  sshd_config.orig  tmp
```

Позначення клавішею `Insert` дозволило скопіювати два файли однією операцією — у командному рядку це був би окремий виклик `cp` з переліком імен.

### Крок 3. Вбудований редактор mc

```
1. Курсор на bak/hosts
2. F4             → відкрити у вбудованому редакторі mcedit
3. Дописати рядок: 192.168.1.10   lab-server
4. F2             → зберегти
5. F10            → вийти
```

```bash
student@lab-vm:~/lab9$ tail -2 bak/hosts
::1     ip6-localhost ip6-loopback
192.168.1.10   lab-server
```

Редактор `mcedit` працює як звичайний текстовий редактор із меню — він зручний для швидкої правки, але на чужому сервері може бути не встановлений, на відміну від `vi`.

### Крок 4. Перші кроки у vi

```bash
student@lab-vm:~/lab9$ vi conf/notes.txt
```

```
i                     → режим вставки
Лабораторна робота 9
Робота в текстовому режимі
Esc                   → командний режим
:w                    → зберегти
:set number           → показати номери рядків
o                     → новий рядок нижче, режим вставки
Автор: Студент
Esc
:wq                   → зберегти й вийти
```

```bash
student@lab-vm:~/lab9$ cat -n conf/notes.txt
     1	Лабораторна робота 9
     2	Робота в текстовому режимі
     3	Автор: Студент
```

### Крок 5. Переміщення, видалення, скасування

```bash
student@lab-vm:~/lab9$ vi conf/sshd_config.orig
```

```
:set number           → номери рядків
G                     → кінець файлу
gg                    → початок файлу
/Port                 → знайти слово Port
n                     → наступне збігання
dd                    → видалити поточний рядок
u                     → скасувати видалення
:15                   → перейти до рядка 15
3dd                   → видалити три рядки
u                     → скасувати
:q!                   → вийти без збереження
```

Команда `u` скасовує останню дію, `Ctrl+r` повертає скасоване. Вихід через `:q!` гарантує, що жодна експериментальна зміна не потрапить у файл.

### Крок 6. Пошук і заміна

```bash
student@lab-vm:~/lab9$ cp conf/sshd_config.orig conf/sshd_config.test
student@lab-vm:~/lab9$ vi conf/sshd_config.test
```

```
/PermitRootLogin      → знайти параметр
:%s/#Port 22/Port 2222/g     → замінити в усьому файлі
:%s/yes/no/gc                → замінити з підтвердженням (y/n для кожного)
:w                            → зберегти
:q                            → вийти
```

```bash
student@lab-vm:~/lab9$ grep -n "Port 2222" conf/sshd_config.test
13:Port 2222

student@lab-vm:~/lab9$ diff conf/sshd_config.orig conf/sshd_config.test | head -4
13c13
< #Port 22
---
> Port 2222
```

Команда `diff` підтверджує, що змінено саме те, що планувалося: у роботі з конфігураційними файлами таку перевірку роблять завжди перед застосуванням змін.

## Порядок виконання роботи

1. Отримати в викладача номер індивідуального варіанта.

2. Встановити (за потреби) пакети `mc` і `vim`. Створити структуру `~/lab9` з підкаталогами `conf` і `bak`, скопіювати в `conf` три конфігураційні файли, зазначені у варіанті.

3. Запустити mc. Описати у звіті призначення обох панелей, рядка функціональних клавіш і меню F9.

4. Виконати в mc такі операції: позначити два файли клавішею `Insert` і скопіювати їх на протилежну панель, перейменувати один файл, створити каталог, переглянути файл клавішею F3. Кожну дію підтвердити знімком екрана.

5. Скористатися можливостями меню F9: порівняти каталоги `conf` і `bak`, виконати пошук файлу за маскою свого варіанта. Описати результат.

6. Відредагувати файл вбудованим редактором mc (F4): додати рядок, зазначений у варіанті, зберегти клавішею F2.

7. Створити у vi файл `notes.txt` із трьома рядками тексту. Продемонструвати перехід між режимами, увімкнути нумерацію рядків, зберегти файл.

8. Виконати у vi на копії конфігураційного файлу: перехід до кінця й початку файлу, пошук параметра свого варіанта, видалення рядка, скасування видалення, перехід до заданого рядка. Вийти без збереження.

9. Виконати заміну параметра згідно з варіантом командою `:%s`, зберегти файл під новим іменем і підтвердити зміну командою `diff`.

10. Виконати додаткове завдання свого варіанта.

11. Оформити звіт і зробити висновок.

## Контрольні запитання

Запитання згруповано за рівнями навчальних досягнень. Для позитивної оцінки студент має відповісти на запитання середнього рівня, оцінка «добре» потребує відповідей достатнього рівня, оцінка «відмінно» — високого.

4. Назвіть три режими редактора vi.
5. Якими клавішами переходять у режим вставки?
6. Як зберегти файл і вийти з vi?
7. Як вийти з vi без збереження змін?
8. Якою командою виконують пошук тексту у vi?

### Достатній рівень (конструктивно-варіативний)

1. Чому набраний одразу після запуску vi текст «зникає» і що робити в цій ситуації?
2. Чим `i` відрізняється від `a` та `o`? Наведіть задачу для кожної команди.
3. Поясніть схему «кількість + дія + об'єкт» на прикладі команд `3dd` і `2yy`.
4. Запишіть команду заміни всіх входжень слова в файлі з підтвердженням кожної заміни.
5. Що робить `Ctrl+O` у mc і коли це потрібно?
6. Чим вбудований редактор mcedit зручніший за vi, а чим поступається йому?
7. Як зберегти зміни, якщо файл відкрито без прав на запис?
8. Як у mc порівняти вміст двох каталогів і навіщо це потрібно адміністраторові?

### Високий рівень (творчий)

1. Сервер доступний лише через SSH, графічної оболонки немає, потрібно терміново виправити помилку в конфігурації служби. Опишіть повний порядок дій із зазначенням інструментів і поясніть, чому обрали саме їх.
2. Поясніть, чому модальність vi, яка спершу здається незручною, у роботі досвідченого адміністратора дає виграш у швидкості. Проілюструйте прикладом із цієї роботи.
3. Сформулюйте правила безпечного редагування системних конфігураційних файлів і обґрунтуйте кожне з них наслідками помилки.
4. Порівняйте роботу з файлами в mc і в чистому командному рядку за трьома критеріями: швидкість, надійність, можливість автоматизації. Для яких задач ви оберете кожен варіант?
