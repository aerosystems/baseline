**Мета:** навчитися виконувати повний цикл операцій над файлами й каталогами засобами командного рядка Windows: навігацію за абсолютними та відносними шляхами, створення й копіювання структур, масові операції за масками імен, керування атрибутами, видалення, а також перенаправлення виводу й пошук у текстових файлах.

## Теоретичні відомості

### 1 Файлова система очима командного рядка

Управління файлами — одна з п’яти основних функцій операційної системи. Саме ОС приховує від програм фізичну структуру диска й надає натомість звичну ієрархію: диски, каталоги, файли. Кожна команда, розглянута в цій роботі, урешті-решт зводиться до системних викликів до менеджера файлової системи.

Шлях до файлу буває абсолютним і відносним. Абсолютний починається з літери диска і однозначно вказує на об’єкт незалежно від того, де ви зараз перебуваєте: C:\Users\Student\Desktop\report.txt. Відносний відлічується від поточного каталогу: Desktop\report.txt, ..\report.txt, .\report.txt. Два крапки означають батьківський каталог, одна — поточний.

Якщо шлях містить пробіли, його беруть у подвійні лапки: cd "Program Files". Без лапок командний процесор сприйме пробіл як роздільник аргументів і повідомить про помилку синтаксису.

### 2 Навігація

У кожного диска командний процесор запам’ятовує власний поточний каталог. Через це команда cd D:\Data, виконана з диска C, змінить поточний каталог диска D, але сам процесор залишиться на диску C — візуально нічого не станеться. Щоб перейти одночасно на інший диск і в інший каталог, потрібен ключ /d:

```
cd Desktop            :: у підкаталог поточного каталогу
cd ..                 :: на рівень вище
cd \                  :: до кореня поточного диска
D:                    :: змінити диск без зміни каталогу
cd /d D:\Data         :: змінити диск і каталог одночасно
pushd %SystemRoot%    :: перейти, запам’ятавши поточний каталог
popd                  :: повернутися туди, звідки викликали pushd
```

Пара pushd / popd зручна, коли треба ненадовго відлучитися в інший каталог і гарантовано повернутися: вона працює як стек, тому виклики можна вкладати.

### 3 Маски імен файлів

Маска (шаблон, wildcard) дозволяє однією командою охопити групу файлів. Використовуються два символи: зірочка заміняє будь-яку кількість будь-яких символів, знак питання — рівно один символ.

```
*.txt        усі файли з розширенням txt
report.*     усі файли з іменем report і будь-яким розширенням
*.*          усі файли, що мають розширення
*            усі файли взагалі
data?.txt    data1.txt, data2.txt, dataA.txt, але не data10.txt
??.log       файли, ім’я яких складається рівно з двох символів
```

Маска розкривається не командою, а самою командою-адресатом, тому одна й та сама маска в dir і в del дає однаковий набір файлів. Це властивість, на якій ґрунтується головне правило безпеки: перш ніж виконати del із маскою, виконайте з тією самою маскою dir і подивіться, що саме потрапить під видалення.

### 4 Перегляд вмісту каталогу

Таблиця 1 — Основні ключі команди dir

| Ключ | Дія | Приклад |
|---|---|---|
| `/b` | Тільки імена, без заголовків і підсумків | `dir /b` |
| `/s` | Рекурсивно, включно з підкаталогами | `dir /s *.log` |
| `/a` | Показати всі файли, зокрема приховані й системні | `dir /a` |
| `/a:h` | Тільки приховані | `dir /a:h` |
| `/a:d` | Тільки каталоги | `dir /a:d` |
| `/o:n` | Сортувати за іменем | `dir /o:n` |
| `/o:-s` | Сортувати за розміром, від більшого | `dir /o:-s` |
| `/o:d` | Сортувати за датою зміни | `dir /o:d` |
| `/w` | Широкий формат, у кілька колонок | `dir /w` |

Ключі комбінуються: dir /s /b *.txt виведе повні шляхи всіх текстових файлів дерева, по одному на рядок. Такий формат зручно передавати далі у файл або в іншу команду.

### 5 Три команди копіювання

У Windows співіснують три команди копіювання, і це не надмірність: вони працюють на різних рівнях.

Таблиця 2 — Порівняння команд копіювання

| Команда | Що вміє | Чого не вміє | Коли застосовувати |
|---|---|---|---|
| `copy` | Копіює файли одного каталогу; вміє об’єднувати файли | Не бачить підкаталогів | Один файл або кілька файлів за маскою |
| `xcopy` | Копіює дерево каталогів, приховані файли, атрибути | Не відновлюється після обриву, повільна на великих обсягах | Разове копіювання структури |
| `robocopy` | Багатопотокове копіювання, журнал, продовження після обриву, синхронізація | Складніший синтаксис, надлишкова для одного файлу | Резервне копіювання, великі обсяги |

```
copy file.txt backup.txt           :: копія одного файлу
copy *.wav audio\                  :: усі wav в підкаталог audio
copy part1.txt+part2.txt all.txt   :: об’єднання файлів
```

```
xcopy /s /i src dest               :: з підкаталогами (/i — dest це каталог)
xcopy /s /e /h /y src dest         :: + порожні каталоги, приховані, без запитів
```

```
robocopy src dest /e               :: дерево разом з порожніми каталогами
robocopy src dest /e /mt:8         :: у вісім потоків
robocopy src dest /e /log:copy.log :: із журналом
robocopy src dest /e /l            :: лише показати, що було б скопійовано
```

**Небезпечні ключі robocopy.** Ключ /mir приводить каталог-приймач у точну відповідність до джерела, а це означає видалення з приймача всього, чого немає в джерелі. Помилка в шляху джерела перетворює /mir на команду очищення. Ключ /mov видаляє файли з джерела після копіювання. У цій лабораторній роботі обидва ключі не використовуються. Перед будь-яким застосуванням robocopy корисно спершу виконати ту саму команду з ключем /l — вона нічого не змінить, лише покаже перелік дій.

### 6 Переміщення, перейменування, видалення

```
move old.txt D:\arch\              :: перемістити файл
move old.txt new.txt               :: перемістити = перейменувати
ren report.txt report_2026.txt     :: перейменувати
ren *.txt *.bak                    :: масове перейменування за маскою
```

```
del file.txt                       :: видалити файл
del /q *.tmp                       :: без підтвердження
del /s *.tmp                       :: рекурсивно в усіх підкаталогах
del /f readonly.txt                :: примусово, попри атрибут «лише читання»
del /a:h *.txt                     :: приховані файли
```

```
rd empty                           :: видалити порожній каталог
rd /s folder                       :: разом із вмістом, із підтвердженням
rd /s /q folder                    :: разом із вмістом, без підтвердження
```

Команда ren працює тільки в межах одного каталогу й не приймає шлях у другому аргументі: перейменувати з переміщенням можна лише командою move. Масове перейменування ren *.txt *.bak змінює розширення всім файлам поточного каталогу — команда не питає підтвердження і не має ключа для перевірки, тому перед нею теж варто виконати dir з тією самою маскою.

### 7 Атрибути файлів

Атрибути — це метадані, які файлова система зберігає поряд з іменем файлу. Найуживаніші чотири: R (лише читання), H (прихований), S (системний), A (архівний). Команда attrib без аргументів показує атрибути, зі знаком плюс встановлює, зі знаком мінус знімає.

```
attrib file.txt          :: показати атрибути
attrib +r file.txt       :: захистити від зміни й видалення
attrib -r file.txt       :: зняти захист
attrib +h +s file.txt    :: прихований і системний
attrib /s /d *.txt       :: рекурсивно, включно з каталогами
```

Атрибут R реально впливає на поведінку команд: del для такого файлу завершиться повідомленням про відмову в доступі, і потрібен буде ключ /f. Атрибут H прибирає файл зі звичайного виводу dir — побачити його можна лише з ключем /a:h.

### 8 Перенаправлення виводу та конвеєр

Таблиця 3 — Перенаправлення та конвеєр

| Символ | Дія | Приклад |
|---|---|---|
| `>` | Записати вивід у файл, перезаписавши його | `dir /s /b > list.txt` |
| `>>` | Дописати вивід у кінець файлу | `echo Готово >> list.txt` |
| `2>` | Перенаправити тільки повідомлення про помилки | `dir nosuch 2> err.txt` |
| `2>&1` | Об’єднати помилки зі звичайним виводом | `dir /s > all.txt 2>&1` |
| `\|` | Передати вивід однієї команди на вхід іншої | `dir /s /b \| find /c ":"` |
| `<` | Взяти вхідні дані з файлу | `sort < list.txt` |

Два додаткові прийоми створення файлів: type nul > empty.txt створює порожній файл, а copy con notes.txt дозволяє набрати вміст із клавіатури й завершити введення комбінацією Ctrl+Z та Enter.

### 9 Пошук у файлах

Команда find шукає рядок як є, findstr вміє працювати з регулярними виразами й переглядати дерево каталогів.

```
find "error" log.txt         :: рядки, що містять error
find /i "error" log.txt      :: без урахування регістру
find /c "error" log.txt      :: тільки кількість таких рядків
find /v "error" log.txt      :: рядки, які НЕ містять error
```

```
findstr /i "error" *.log     :: у всіх файлах поточного каталогу
findstr /s /i "error" *.log  :: рекурсивно по дереву
findstr /n "error" log.txt   :: з номерами рядків
findstr /r "^[0-9]" log.txt  :: регулярний вираз: рядки, що починаються з цифри
```

### 10 Ті самі задачі мовою PowerShell

Таблиця 4 — Відповідність команд CMD і PowerShell

| CMD | PowerShell |
|---|---|
| `dir /s /b` | `Get-ChildItem -Recurse -Name` |
| `copy a.txt b.txt` | `Copy-Item a.txt b.txt` |
| `xcopy /s src dest` | `Copy-Item src dest -Recurse` |
| `move a.txt b.txt` | `Move-Item a.txt b.txt` |
| `del /s *.tmp` | `Remove-Item *.tmp -Recurse` |
| `findstr /s "error" *.log` | `Select-String "error" *.log -Recurse` |
| `dir /o:-s` | `Get-ChildItem \| Sort-Object Length -Descending` |

Різниця не лише в іменах. CMD передає по конвеєру текст, і щоб дізнатися сумарний розмір файлів, довелося б розбирати рядки виводу dir. PowerShell передає об’єкти з числовими властивостями, тому та сама задача розв’язується одним конвеєром без жодного розбору тексту.

## Приклад виконання

Наведена послідовність виконується на довільній машині. Конкретні числа — кількість файлів, розміри, час — у вас будуть іншими; у звіт вносяться саме ваші результати.

### Крок 1. Пісочниця та навігація

```
C:\Users\Student> cd %USERPROFILE%\Desktop
C:\Users\Student\Desktop> md LAB2
C:\Users\Student\Desktop> cd LAB2
C:\...\LAB2> md src docs bak "test folder"
C:\...\LAB2> dir /a:d /b
bak
docs
src
test folder
```

```
C:\...\LAB2> cd test folder
C:\...\LAB2\test folder> cd ..
```

```
C:\...\LAB2> cd "test folder"
C:\...\LAB2\test folder> cd ..
C:\...\LAB2> pushd %SystemRoot%\Media
C:\Windows\Media> dir /b *.wav | find /c ".wav"
70
C:\Windows\Media> popd
C:\...\LAB2>
```

Windows CMD дозволяє використовувати пробіли в якості значення аргументу, який приймає cd «test folder» і «"test folder"» працюють однаково.

Маска ??.wav не знайшла нічого: серед файлів немає жодного, ім’я якого складається рівно з двох символів. Маска *.wav дала б усі сімдесят.

## Порядок виконання роботи

1. Отримати в викладача номер індивідуального варіанта.

2. Створити на робочому столі навчальний каталог LAB2 і всередині нього підкаталоги src, docs, bak, а також один каталог, ім’я якого містить пробіл. Перевірити, що перехід у нього без лапок не спрацьовує, і зафіксувати повідомлення системи.

3. Скопіювати в каталог src вміст вихідного каталогу, зазначеного у варіанті. Підрахувати командою dir із конвеєром, скільки об’єктів потрапило до src.

4. Виконати чотири різні запити до каталогу src: вивести лише імена файлів; вивести файли рекурсивно за маскою свого варіанта; відсортувати за розміром від більшого; вивести лише каталоги. Навести використані команди з ключами.

5. Виконати копіювання каталогу src трьома способами — командами copy, xcopy і robocopy — у каталоги copy1, copy2 і copy3 відповідно. Заміряти час кожної операції командою echo %time% до і після. Підрахувати кількість об’єктів у кожній копії та пояснити виявлену різницю.

6. У каталозі copy1 виконати масове перейменування за маскою свого варіанта. Переконатися командою dir, що перейменовано саме ті файли, які очікувалися.

7. Встановити атрибут, зазначений у варіанті, на один з файлів. Спробувати видалити цей файл звичайною командою del, зафіксувати повідомлення системи, після чого видалити його з відповідним ключем.

8. Видалити каталог copy1 повністю. Перевірити, що його немає ані у звичайному виводі dir, ані у виводі з ключем /a.

9. Сформувати у файлі docs\listing.txt повний рекурсивний перелік каталогу src. Дописати в кінець файлу рядок із власним прізвищем. Підрахувати кількість рядків, що містять маску вашого варіанта, і знайти їх із номерами рядків.

10. Перенаправити в окремий файл повідомлення про помилку, звернувшись до неіснуючого файлу. Пояснити, чому для цього потрібен саме символ 2>, а не >.

11. Виконати додаткове завдання свого варіанта.

12. Розв’язати одну з задач пунктів 4 або 9 засобами PowerShell і порівняти обидва розв’язки.

## Вимоги до звіту

Звіт оформлюється на бланку встановленого зразка і має містити:

- тему, мету та обладнання;

- постановку задачі за індивідуальним варіантом: вихідний каталог, маска, атрибут;

- таблицю виконаних команд із зазначенням призначення кожного використаного ключа;

- знімки екрана, які підтверджують результат кожного пункту, зокрема повідомлення про відмову в доступі та результат перейменування за маскою;

- таблицю порівняння трьох способів копіювання: команда, час виконання, кількість скопійованих об’єктів;

- відповідь на додаткове завдання варіанта;

- висновок, у якому пояснено, чому в Windows існують три різні команди копіювання і за яким критерієм обирають між ними.

## Контрольні запитання

Запитання згруповано за рівнями навчальних досягнень. Для позитивної оцінки студент має відповісти на запитання середнього рівня; оцінка «добре» передбачає відповіді на запитання достатнього рівня, оцінка «відмінно» — високого.

### Середній рівень (репродуктивний)

1. Чим абсолютний шлях відрізняється від відносного? Наведіть приклад кожного.

2. Що означають позначення «..» і «.» у шляху?

3. Що робить ключ /d команди cd?

4. Які символи використовуються в масках імен файлів і що заміняє кожен із них?

5. Назвіть призначення ключів /b, /s і /a команди dir.

6. Які чотири атрибути файлу ви знаєте? Якою командою їх встановлюють і знімають?

7. Чим символ > відрізняється від >> під час перенаправлення виводу?

8. Яка команда видаляє каталог разом із вмістом без запитів?

### Достатній рівень (конструктивно-варіативний)

1. Запишіть команду, яка виведе повні шляхи всіх файлів з розширенням log у поточному каталозі та всіх його підкаталогах, по одному на рядок.

2. Чим copy відрізняється від xcopy? Наведіть задачу, яку copy розв’язати не може.

3. Чим del відрізняється від rd? Що станеться, якщо застосувати del до каталогу?

4. Чому команда del не видаляє файл з атрибутом R і як це обійти?

5. Що зробить команда ren *.txt *.bak і в якому саме каталозі? Чи торкнеться вона підкаталогів?

6. Запишіть команду, яка запише повідомлення про помилки в один файл, а звичайний вивід — в інший.

7. Чому команда cd D:\Data, виконана з диска C, візуально нічого не змінює?

8. Побудуйте конвеєр, який підрахує кількість файлів у дереві каталогів.

### Високий рівень (творчий)

1. Потрібно щовечора копіювати робочий каталог на зовнішній диск так, щоб копіювалися лише змінені файли, а процес переживав від’єднання диска. Яку з трьох команд копіювання ви оберете і з якими ключами? Обґрунтуйте вибір.

2. Оцініть наслідки виконання команди del /s /q *.tmp з кореня системного диска. Які категорії файлів постраждають і чим це загрожує системі? Як перевірити команду, не виконуючи її?

3. Чому в Windows існують три окремі команди копіювання замість однієї універсальної? Сформулюйте критерій, за яким між ними обирають.

4. Після копіювання командою copy у каталозі-приймачі виявилося менше об’єктів, ніж у джерелі. Поясніть причину і скажіть, що це говорить про рівень абстракції, на якому працює ця команда.

5. Запропонуйте порядок дій, який унеможливлює випадкове видалення зайвих файлів під час роботи з масками, і поясніть, чому кожен крок цього порядку потрібен.

6. Порівняйте текстовий конвеєр CMD і об’єктний конвеєр PowerShell на задачі «знайти сумарний розмір усіх файлів дерева». Оцініть, у якому випадку кожен із підходів виграє.
