## Linux — основа сучасної інфраструктури

Linux працює скрізь:
- **96%** веб-серверів
- **85%** смартфонів (Android)
- **100%** суперкомп'ютерів TOP500
- **Tesla**, SpaceX, NASA Mars rovers
- Ваш роутер, Smart TV, холодильник

При цьому на десктопах лише ~4%. Чому така різниця? Розберемося.

### Практичні команди

```bash
# Версія ядра
uname -r
# Приклад: 6.5.0-44-generic

# Повна інформація
uname -a

# Де знаходиться ядро
ls -la /boot/vmlinuz*

# Параметри завантаження
cat /proc/cmdline

# Завантажені модулі ядра
lsmod | head -20

# Інформація про модуль
modinfo ext4

# Параметри ядра (runtime)
sysctl -a | head -20

# Змінити параметр (тимчасово)
sudo sysctl vm.swappiness=10

# Логи ядра
dmesg | tail -30
journalctl -k
```

## Користувачі та права

```
┌─────────────────────────────────────────────────────────────────┐
│                    ПРАВА ДОСТУПУ В LINUX                        │
│                                                                 │
│   ls -la file.txt                                              │
│   -rw-r--r-- 1 user group 1234 Jan 15 10:30 file.txt          │
│   ││  │  │                                                     │
│   ││  │  └── others: read only                                │
│   ││  └───── group: read only                                 │
│   │└──────── owner: read + write                              │
│   └───────── type: - (file), d (dir), l (link)                │
│                                                                 │
│   Числове представлення:                                       │
│   r=4, w=2, x=1                                                │
│   rw-r--r-- = 644                                              │
│   rwxr-xr-x = 755                                              │
│   rwx------ = 700                                              │
└─────────────────────────────────────────────────────────────────┘
```

```bash
# Поточний користувач
whoami
id

# Змінити права
chmod 755 script.sh
chmod +x script.sh      # Додати executable
chmod u+w,g-w file.txt  # User +write, group -write

# Змінити власника
sudo chown user:group file.txt

# Список користувачів
cat /etc/passwd

# Групи користувача
groups
groups username
```


```bash
# Дерево процесів
pstree -p

# Список процесів
ps aux
ps aux | grep nginx

# Інтерактивний моніторинг
htop
top

# systemd: статус сервісу
systemctl status nginx

# Запустити/зупинити
sudo systemctl start nginx
sudo systemctl stop nginx
sudo systemctl restart nginx

# Увімкнути автозапуск
sudo systemctl enable nginx

# Логи сервісу
journalctl -u nginx -f
```

## Чому Linux?

| Перевага | Пояснення |
|----------|-----------|
| **Безкоштовний** | Немає ліцензійних витрат |
| **Open Source** | Можна модифікувати, аудитувати код |
| **Стабільний** | Сервери працюють роками без ребуту |
| **Безпечний** | Швидкі патчі, менше malware |
| **Гнучкий** | Від IoT до суперкомп'ютерів |
| **Ефективний** | Менше ресурсів для тієї ж роботи |
| **Спільнота** | Величезна база знань, підтримка |

## Підсумок

| Компонент | Опис |
|-----------|------|
| **Kernel** | Ядро Linux — керує hardware |
| **GNU tools** | Базові утиліти (bash, coreutils) |
| **systemd** | Система ініціалізації |
| **Package Manager** | apt, dnf, pacman |
| **Filesystem** | ext4, XFS, Btrfs |

**Ключові файли:**
- `/etc/passwd` — користувачі
- `/etc/fstab` — монтування
- `/var/log/` — логи
- `/proc/`, `/sys/` — інформація про систему

На наступній лекції розглянемо різні дистрибутиви Linux та як обрати потрібний.
