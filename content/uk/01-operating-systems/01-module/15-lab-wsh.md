## Теоретичні відомості

### 1 Що таке Windows Script Host

Windows Script Host — вбудована підсистема виконання сценаріїв, яка з'явилася ще у Windows 98 і присутня в усіх сучасних версіях. На відміну від пакетного файлу, сценарій WSH — це повноцінна програма з мовою, що має типи даних, функції, обробку помилок і, найголовніше, доступ до об'єктної моделі системи через технологію COM.

WSH сам мову не реалізує: він завантажує механізм мови (`VBScript` або `JScript`) і надає йому набір власних об'єктів. Тому файл `.vbs` і файл `.js` виконує та сама підсистема — різниця лише в синтаксисі.

**VBScript доживає свій вік.** 2023 року Microsoft оголосила мову застарілою і прибирає її поетапно: у Windows 11 24H2 VBScript уже став «компонентом на вимогу», який поки що встановлено за замовчуванням; далі його вимкнуть за замовчуванням, а згодом видалять із системи зовсім. Головна причина — безпека: файли `.vbs` роками були одним із найпоширеніших способів доставити шкідливу програму. Навіщо тоді ця робота? У багатьох організаціях досі працюють тисячі сценаріїв WSH, і їх треба розуміти, підтримувати й переносити на PowerShell. А об'єктна модель COM, яку ви тут опануєте, лежить і під PowerShell, і під автоматизацією Office.

Таблиця 1 — Два хости виконання сценаріїв

| Характеристика | `wscript.exe` | `cscript.exe` |
|----------------|---------------|---------------|
| Інтерфейс | графічний, вікна повідомлень | консольний, вивід у вікно cmd |
| Вивід `WScript.Echo` | модальне вікно | рядок у консолі |
| Типове застосування | взаємодія з користувачем | автоматизація, планувальник |
| Код повернення | недоступний у скрипті-виклику | доступний через `errorlevel` |

Хост за замовчуванням задають командою `wscript //h:cscript`. Для навчальних задач зручніший `cscript`, бо вивід не доводиться закривати клацанням.

**Кодування файлу сценарію.** WSH читає сценарії лише у двох кодуваннях: ANSI — однобайтовому кодуванні мови системи — та UTF-16 LE, яке Блокнот називає «Юнікод». UTF-8, у якому Блокнот зберігає файли за замовчуванням, WSH не розуміє: українські рядки в лапках перетворяться на набір символів на кшталт `РџСЂРёРІС–С‚`. Тому під час збереження `.vbs` у діалозі «Зберегти як» оберіть кодування ANSI (на системі з українською мовою) або «UTF-16 LE».

### 2 Перший сценарій і аргументи

```vbscript
' hello.vbs — перший сценарій
Option Explicit
Dim name

If WScript.Arguments.Count > 0 Then
    name = WScript.Arguments(0)
Else
    name = "користувач"
End If

WScript.Echo "Привіт, " & name & "!"
WScript.Echo "Сценарій: " & WScript.ScriptName
WScript.Echo "Хост: " & WScript.FullName
WScript.Quit 0
```

Директива `Option Explicit` вимагає оголошувати змінні через `Dim` — з нею друкарська помилка в імені стає видимою одразу, а не перетворюється на «мовчазну» порожню змінну. Об'єкт `WScript` — кореневий: через нього доступні аргументи, ім'я сценарію, вивід та завершення з кодом повернення.

### 3 Об'єктна модель: три головні об'єкти

Реальну роботу виконують COM-об'єкти, які створюють функцією `CreateObject`.

Таблиця 2 — Основні об'єкти сценаріїв WSH

| Об'єкт | Призначення | Приклад можливостей |
|--------|-------------|---------------------|
| `Scripting.FileSystemObject` | файлова система | створення, копіювання, читання файлів, обхід каталогів |
| `WScript.Shell` | оболонка | запуск програм, змінні середовища, реєстр, ярлики |
| `WScript.Network` | мережеве оточення | ім'я комп'ютера й користувача, мережеві диски та принтери |
| `winmgmts:` (WMI) | відомості про систему | процеси, служби, диски, ОС, обладнання |

### 4 Робота з файловою системою

```vbscript
Option Explicit
Dim fso, folder, file, stream

Set fso = CreateObject("Scripting.FileSystemObject")

' Усі шляхи — відносно каталогу, де лежить сам сценарій (LAB5)
Dim base
base = fso.GetParentFolderName(WScript.ScriptFullName)

' Створення структури
If Not fso.FolderExists(base & "\out") Then
    fso.CreateFolder base & "\out"
End If

' Запис у файл
Set stream = fso.CreateTextFile(base & "\out\report.txt", True, True)
stream.WriteLine "Звіт сформовано " & Now
stream.Close

' Обхід каталогу
Set folder = fso.GetFolder(base & "\src")
For Each file In folder.Files
    WScript.Echo file.Name & " — " & file.Size & " байт, змінено " & _
                 file.DateLastModified
Next
```

Третій аргумент `CreateTextFile` вмикає запис у Unicode (UTF-16). Без нього файл пишеться в кодуванні ANSI, і на комп'ютері з іншою мовою системи українські літери перетворяться на знаки питання. Колекція `folder.SubFolders` дає підкаталоги, а рекурсивний обхід дерева пишуть окремою процедурою, що викликає саму себе.

### 5 Оболонка: оточення, запуск програм, ярлики

```vbscript
Option Explicit
Dim shell, exec, link

Set shell = CreateObject("WScript.Shell")

WScript.Echo "TEMP: " & shell.ExpandEnvironmentStrings("%TEMP%")

' Запуск програми і очікування завершення
shell.Run "notepad.exe", 1, True

' Запуск із перехопленням виводу
Set exec = shell.Exec("cmd /c ver")
WScript.Echo Trim(exec.StdOut.ReadAll())

' Створення ярлика на робочому столі
Set link = shell.CreateShortcut(shell.SpecialFolders("Desktop") & "\LAB5.lnk")
link.TargetPath = shell.SpecialFolders("Desktop") & "\LAB5"
link.Description = "Навчальний каталог"
link.Save
```

Метод `Run` повертає код завершення програми, якщо третій аргумент дорівнює `True`; метод `Exec` натомість дає доступ до потоків `StdOut` і `StdErr` — саме так сценарій читає результат роботи консольної утиліти.

### 6 Відомості про систему через WMI

WMI — це служба, що надає уніфікований доступ до відомостей про обладнання, ОС і процеси. Запит формулюють мовою WQL, схожою на SQL.

```vbscript
Option Explicit
Dim wmi, items, item

Set wmi = GetObject("winmgmts:\\.\root\cimv2")

Set items = wmi.ExecQuery("SELECT * FROM Win32_OperatingSystem")
For Each item In items
    WScript.Echo "ОС: " & item.Caption
    WScript.Echo "Збірка: " & item.BuildNumber
    WScript.Echo "Пам'ять: " & Int(item.TotalVisibleMemorySize / 1024) & " МБ"
Next

Set items = wmi.ExecQuery("SELECT Name, ProcessId, WorkingSetSize " & _
                          "FROM Win32_Process WHERE Name = 'explorer.exe'")
For Each item In items
    WScript.Echo item.Name & " PID=" & item.ProcessId & " " & _
                 Int(item.WorkingSetSize / 1048576) & " МБ"
Next
```

Той самий запит у PowerShell записується одним рядком `Get-CimInstance Win32_OperatingSystem` — це наочно показує, чому сучасну автоматизацію будують на PowerShell, тоді як WSH лишається у спадкових сценаріях, які досі працюють у багатьох організаціях.

### 7 Обробка помилок

У VBScript немає звичних блоків `try/catch`. Замість них вмикають режим продовження після помилки й перевіряють об'єкт `Err`.

```vbscript
On Error Resume Next
Set stream = fso.OpenTextFile(base & "\missing.txt", 1)
If Err.Number <> 0 Then
    WScript.Echo "Помилка " & Err.Number & ": " & Err.Description
    Err.Clear
    WScript.Quit 1
End If
On Error Goto 0
```

Режим `On Error Resume Next` вмикають на мінімальну ділянку коду й вимикають одразу після перевірки: залишений на весь сценарій, він приховує справжні причини збою.

### Крок 2. Інвентаризація каталогу

```vbscript
' inventory.vbs
Option Explicit
Dim fso, folder, file, stream, total, base

Set fso = CreateObject("Scripting.FileSystemObject")
base = fso.GetParentFolderName(WScript.ScriptFullName)
Set folder = fso.GetFolder(base & "\src")
Set stream = fso.CreateTextFile(base & "\out\inventory.txt", True, True)

total = 0
For Each file In folder.Files
    stream.WriteLine file.Name & vbTab & file.Size & vbTab & file.DateLastModified
    total = total + file.Size
Next

stream.WriteLine "Разом: " & folder.Files.Count & " файлів, " & total & " байт"
stream.Close
WScript.Echo "Звіт: out\inventory.txt"
```

### Крок 4. Той самий сценарій мовою JScript

```javascript
// inventory.js
var fso = new ActiveXObject("Scripting.FileSystemObject");
var folder = fso.GetFolder(fso.GetParentFolderName(WScript.ScriptFullName) + "\\src");
var files = new Enumerator(folder.Files);
var total = 0;

for (; !files.atEnd(); files.moveNext()) {
    var file = files.item();
    WScript.Echo(file.Name + " — " + file.Size + " байт");
    total += file.Size;
}
WScript.Echo("Разом: " + total + " байт");
```

Об'єктна модель однакова: змінюється лише синтаксис мови та спосіб обходу колекції — у JScript для цього потрібен `Enumerator`.

### Крок 5. Перевірка коду повернення

```cmd
C:\...\LAB5> cscript //nologo check.vbs missing.txt
Помилка 53: File not found
C:\...\LAB5> echo %errorlevel%
1
```

Саме завдяки коду повернення сценарій WSH вбудовують у пакетний файл або в завдання планувальника: батьківський процес дізнається про невдачу без розбору виводу.

Запитання згруповано за рівнями навчальних досягнень. Для позитивної оцінки студент має відповісти на запитання середнього рівня, оцінка «добре» потребує відповідей достатнього рівня, оцінка «відмінно» — високого.

### Середній рівень (репродуктивний)

1. Що таке Windows Script Host і які мови він підтримує «з коробки»?
2. Чим `wscript.exe` відрізняється від `cscript.exe`?
3. Якою функцією створюють COM-об'єкт у VBScript?
4. Для чого призначений об'єкт `Scripting.FileSystemObject`?
5. Які можливості дає об'єкт `WScript.Shell`?
6. Як передати сценарію аргумент і як прочитати його в коді?
7. Що робить директива `Option Explicit`?
8. Якою командою сценарій завершується з ненульовим кодом повернення?

### Достатній рівень (конструктивно-варіативний)

1. Запишіть фрагмент, який створює текстовий файл у кодуванні Unicode й записує в нього рядок з українськими літерами. Поясніть роль третього аргументу `CreateTextFile`.
2. Чим метод `Run` об'єкта `WScript.Shell` відрізняється від методу `Exec`? Коли потрібен саме `Exec`?
3. Як у VBScript обробити помилку звернення до неіснуючого файлу? Чому `On Error Resume Next` не залишають на весь сценарій?
4. Побудуйте WQL-запит, який поверне процеси з іменем `notepad.exe`.
5. Чим обхід колекції `folder.Files` у VBScript відрізняється від аналогічного обходу в JScript?
6. Як сценарій WSH повідомляє пакетному файлу про невдале виконання?
7. Запишіть фрагмент, який виведе значення змінної середовища `TEMP` двома різними способами.
8. Чому сценарій із вікном `Popup` не годиться для запуску за розкладом?

### Високий рівень (творчий)

1. Організація має сотню робочих станцій і потребує щотижневого звіту про вільне місце на дисках. Опишіть, як розв'язати задачу засобами WSH: які об'єкти, як зібрати результати, які обмеження виникнуть.
2. Сценарій `.vbs` — класичний носій шкідливого коду. Поясніть, які саме можливості WSH роблять його небезпечним і якими засобами системи цей ризик обмежують.
3. Порівняйте WSH і PowerShell за трьома критеріями: доступ до системи, читабельність коду, наявність у сучасних версіях Windows. У яких випадках вибір WSH сьогодні виправданий?
4. Той самий алгоритм реалізовано пакетним файлом і сценарієм WSH. Сформулюйте критерії, за якими ви оберете один із варіантів, і проілюструйте кожен критерій прикладом із цієї роботи.
