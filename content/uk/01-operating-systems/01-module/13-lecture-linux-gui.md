## Linux — не тільки командний рядок

Сучасний Linux має потужний графічний інтерфейс, який не поступається Windows чи macOS. На відміну від них, у Linux ви можете **обирати** графічне середовище.

## Display Server: X11 vs Wayland

```
┌─────────────────────────────────────────────────────────────────┐
│                    X11 vs WAYLAND                               │
│                                                                 │
│   X11 (X Window System)            Wayland                     │
│   ═══════════════════════          ════════                    │
│   • 1984 рік                       • 2008 рік                  │
│   • Клієнт-сервер модель           • Compositor модель         │
│   • Сервер Xorg                    • Compositor + server       │
│   • Network transparent            • Local-first               │
│                                                                 │
│   X11:                             Wayland:                     │
│   ┌─────────┐                      ┌─────────┐                 │
│   │   App   │                      │   App   │                 │
│   └────┬────┘                      └────┬────┘                 │
│        │ X11 protocol                   │ Wayland protocol    │
│        ▼                                ▼                      │
│   ┌─────────┐                      ┌───────────────┐          │
│   │ X Server│                      │  Compositor   │          │
│   │ (Xorg)  │◄──────────────────┐  │ (Mutter/KWin)│          │
│   └────┬────┘                   │  └───────┬───────┘          │
│        │                        │          │                   │
│        ▼                        │          │                   │
│   ┌─────────┐                   │          │                   │
│   │Compositor│───────────────────┘          │                   │
│   └────┬────┘                              │                   │
│        │                                   ▼                   │
│        ▼                           ┌───────────────┐          │
│      GPU                           │     GPU       │          │
│                                    └───────────────┘          │
│                                                                 │
│   X11 переваги:                    Wayland переваги:          │
│   ✅ Network transparency          ✅ Безпечніший            │
│   ✅ Сумісність legacy             ✅ Швидший                │
│   ✅ Remote desktop                ✅ HiDPI, менше tearing   │
└─────────────────────────────────────────────────────────────────┘
```

```bash
# Який display server використовується?
echo $XDG_SESSION_TYPE
# x11 або wayland
```

### Легкі DE

| DE | RAM | Для кого |
|----|-----|----------|
| **XFCE** | ~400 МБ | Старі ПК, стабільність |
| **LXQt** | ~300 МБ | Дуже старі ПК |
| **MATE** | ~500 МБ | Любителі GNOME 2 |
| **Cinnamon** | ~700 МБ | Перехід з Windows |

## Порівняння DE

| DE | RAM | Кастомізація | Стиль |
|----|-----|--------------|-------|
| GNOME | ~1 ГБ | Низька | macOS |
| KDE | ~800 МБ | Максимальна | Windows |
| XFCE | ~400 МБ | Середня | Класика |
| LXQt | ~300 МБ | Низька | Мінімум |
| Cinnamon | ~700 МБ | Висока | Win 7 |

## Практичні команди

```bash
# Поточне середовище
echo $XDG_CURRENT_DESKTOP
echo $DESKTOP_SESSION

# Версія
gnome-shell --version  # GNOME
plasmashell --version  # KDE

# Доступні сесії
ls /usr/share/xsessions/

# Встановити DE (Ubuntu)
sudo apt install kubuntu-desktop   # KDE
sudo apt install xubuntu-desktop   # XFCE
```
