## Мета самостійної роботи

Зрозуміти різницю між блочними та потоковими шифрами. Вивчити режими роботи блочних шифрів та їх застосування.

## Теоретичний матеріал

### Потокові шифри (Stream Ciphers)

**Потоковий шифр** шифрує дані по одному біту (або байту) за раз.

```
Відкритий текст:    P₁ P₂ P₃ P₄ P₅ P₆ P₇ P₈ ...
                    ⊕  ⊕  ⊕  ⊕  ⊕  ⊕  ⊕  ⊕
Ключовий потік:     K₁ K₂ K₃ K₄ K₅ K₆ K₇ K₈ ...
                    ↓  ↓  ↓  ↓  ↓  ↓  ↓  ↓
Шифротекст:         C₁ C₂ C₃ C₄ C₅ C₆ C₇ C₈ ...
```

**Ключовий потік** генерується з початкового ключа (seed) за допомогою PRNG (генератора псевдовипадкових чисел).

**Переваги:**
- Швидкі
- Підходять для потокових даних (відео, аудіо)
- Низька затримка

**Недоліки:**
- Не можна повторювати ключ (same key attack)
- Складніша синхронізація

**Приклади:** RC4 (застарів), Salsa20, ChaCha20

### Блочні шифри (Block Ciphers)

**Блочний шифр** шифрує фіксовані блоки даних (64, 128, 256 біт).

```
Відкритий текст:
┌────────────────┬────────────────┬────────────────┐
│   Блок 1       │   Блок 2       │   Блок 3       │
│   (128 біт)    │   (128 біт)    │   (128 біт)    │
└───────┬────────┴───────┬────────┴───────┬────────┘
        ▼                ▼                ▼
    ┌───────┐        ┌───────┐        ┌───────┐
    │ Шифр  │        │ Шифр  │        │ Шифр  │
    │  + K  │        │  + K  │        │  + K  │
    └───┬───┘        └───┬───┘        └───┬───┘
        ▼                ▼                ▼
┌────────────────┬────────────────┬────────────────┐
│ Шифроблок 1    │ Шифроблок 2    │ Шифроблок 3    │
└────────────────┴────────────────┴────────────────┘
```

**Приклади:** DES (64 біт), AES (128 біт), Blowfish

### Режими роботи блочних шифрів

#### ECB (Electronic Codebook)

Найпростіший режим — кожен блок шифрується незалежно.

```
P₁ ──→ [E] ──→ C₁
P₂ ──→ [E] ──→ C₂
P₃ ──→ [E] ──→ C₃
```

**Проблема:** однакові блоки → однаковий шифротекст!

```
Оригінал:           ECB шифрування:
┌─────────────┐     ┌─────────────┐
│ ████  ████  │     │ ████  ████  │  ← Патерн видно!
│             │     │             │
│ ████  ████  │     │ ████  ████  │
└─────────────┘     └─────────────┘
```

#### CBC (Cipher Block Chaining)

Кожен блок XOR-ується з попереднім шифроблоком.

```
     IV
      │
      ▼
P₁ ─→[⊕]─→ [E] ─→ C₁
              │
              └──────┐
                     ▼
P₂ ─────────→ [⊕]─→ [E] ─→ C₂
```

**IV (Initialization Vector)** — випадковий початковий блок.

#### CTR (Counter Mode)

Шифрується лічильник, результат XOR-ується з текстом.

```
Nonce + Counter₁ ─→ [E] ─→ Keystream₁ ⊕ P₁ = C₁
Nonce + Counter₂ ─→ [E] ─→ Keystream₂ ⊕ P₂ = C₂
```

**Переваги CTR:** паралельне шифрування, потоковий режим.

### Padding (доповнення)

Якщо текст не кратний розміру блоку, потрібне доповнення.

**PKCS#7:** доповнюємо байтами, що дорівнюють кількості доданих байтів.

```
Блок 16 байт, текст 11 байт:
[T][E][X][T][05][05][05][05][05] ← 5 байт доповнення
```
