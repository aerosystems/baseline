## Мета самостійної роботи

Вивчити методи криптоаналізу класичних шифрів на основі частотного аналізу. Зрозуміти, чому моноалфавітні шифри є нестійкими.

## Теоретичний матеріал

### Що таке криптоаналіз

**Криптоаналіз** — наука про методи розкриття шифрів без знання ключа. Криптоаналітик шукає слабкості в алгоритмі або його реалізації.

### Типи атак на шифри

| Тип атаки | Що відомо атакуючому | Складність |
|-----------|---------------------|------------|
| **Тільки шифротекст** | Лише зашифроване повідомлення | Найскладніша |
| **Відомий відкритий текст** | Пари (відкритий текст, шифротекст) | Середня |
| **Обраний відкритий текст** | Можна шифрувати довільні повідомлення | Легша |
| **Обраний шифротекст** | Можна дешифрувати довільні повідомлення | Найлегша |

### Частотний аналіз

Кожна мова має характерний розподіл частот літер. Ця властивість зберігається при моноалфавітному шифруванні.

### Алгоритм частотного аналізу

1. Підрахувати частоту кожної літери в шифротексті
2. Порівняти з еталонним розподілом мови
3. Припустити відповідність (найчастіша → E/О)
4. Підставити та перевірити осмисленість
5. Ітеративно уточнювати

### Індекс відповідності (Index of Coincidence)

**Індекс відповідності** — імовірність того, що дві випадково вибрані літери тексту однакові.

```
IC = Σ ni(ni - 1) / N(N - 1)
```

де ni — кількість літери i, N — довжина тексту.

| Мова | IC |
|------|-----|
| Англійська | 0.0667 |
| Українська | ~0.0580 |
| Випадковий текст | 0.0385 (1/26) |

IC допомагає визначити:
- Тип шифру (моно- чи поліалфавітний)
- Мову тексту
- Довжину ключа (для шифру Віженера)
