## Від моноалфавітних до поліграмних шифрів

До цього ми вивчали шифри, які обробляють **по одній літері**. Головна проблема таких шифрів — вразливість до частотного аналізу.

**Ідея поліграмних шифрів:** шифрувати **групи літер** (біграми, триграми), щоб "розмити" частотні характеристики.

```
Моноалфавітний:    H → X,  E → Z,  L → Q,  L → Q,  O → M
                   "HELLO" → "XZQQM"

Біграмний:         HE → XP,  LL → QR,  O? → ...
                   Пари літер → пари літер
```

## Квадрат Полібія (Трисемуса)

### Історія

**Полібій** (200–118 рр. до н.е.) — грецький історик, запропонував систему передачі повідомлень за допомогою факелів.

**Йоганн Трисемус** (1462–1516) — бенедиктинський абат, удосконалив систему для криптографії.

### Побудова квадрата

Квадрат 5×5 містить 25 літер (I та J об'єднуються):

```
    1   2   3   4   5
  ┌───┬───┬───┬───┬───┐
1 │ A │ B │ C │ D │ E │
  ├───┼───┼───┼───┼───┤
2 │ F │ G │ H │ I/J│ K │
  ├───┼───┼───┼───┼───┤
3 │ L │ M │ N │ O │ P │
  ├───┼───┼───┼───┼───┤
4 │ Q │ R │ S │ T │ U │
  ├───┼───┼───┼───┼───┤
5 │ V │ W │ X │ Y │ Z │
  └───┴───┴───┴───┴───┘
```

### Шифрування координатами

Кожна літера замінюється парою цифр (рядок, стовпець):

```
H → (2,3) → "23"
E → (1,5) → "15"
L → (3,1) → "31"
L → (3,1) → "31"
O → (3,4) → "34"

"HELLO" → "23 15 31 31 34"
```

### Квадрат з ключовим словом

```
Ключове слово: CRYPTO

    1   2   3   4   5
  ┌───┬───┬───┬───┬───┐
1 │ C │ R │ Y │ P │ T │  ← Ключ (без повторів)
  ├───┼───┼───┼───┼───┤
2 │ O │ A │ B │ D │ E │  ← Решта алфавіту
  ├───┼───┼───┼───┼───┤
3 │ F │ G │ H │ I/J│ K │
  ├───┼───┼───┼───┼───┤
4 │ L │ M │ N │ O │ P │  (О вже є, пропускаємо)
  ├───┼───┼───┼───┼───┤
5 │ Q │ S │ U │ V │ W │
  └───┴───┴───┴───┴───┘
```

### Реалізація

```python
def create_polybius_square(keyword: str = "") -> dict:
    """Створює квадрат Полібія з ключовим словом."""
    # Формуємо алфавіт
    alphabet = ""
    seen = set()

    # Спочатку ключове слово
    for char in keyword.upper():
        if char.isalpha() and char not in seen:
            if char == 'J':
                char = 'I'
            seen.add(char)
            alphabet += char

    # Потім решта
    for char in "ABCDEFGHIKLMNOPQRSTUVWXYZ":  # без J
        if char not in seen:
            alphabet += char

    # Створюємо таблицю
    encode = {}
    decode = {}
    for i, char in enumerate(alphabet):
        row = i // 5 + 1
        col = i % 5 + 1
        encode[char] = f"{row}{col}"
        decode[f"{row}{col}"] = char

    return {'encode': encode, 'decode': decode, 'grid': alphabet}


def polybius_encrypt(plaintext: str, keyword: str = "") -> str:
    """Шифрування квадратом Полібія."""
    square = create_polybius_square(keyword)
    result = []

    for char in plaintext.upper():
        if char == 'J':
            char = 'I'
        if char in square['encode']:
            result.append(square['encode'][char])

    return ' '.join(result)


def polybius_decrypt(ciphertext: str, keyword: str = "") -> str:
    """Дешифрування квадратом Полібія."""
    square = create_polybius_square(keyword)
    pairs = ciphertext.split()
    result = []

    for pair in pairs:
        if pair in square['decode']:
            result.append(square['decode'][pair])

    return ''.join(result)


# Приклад
message = "HELLO"
encrypted = polybius_encrypt(message)
print(f"Зашифровано: {encrypted}")  # 23 15 31 31 34

decrypted = polybius_decrypt(encrypted)
print(f"Розшифровано: {decrypted}")  # HELLO
```

## Шифр Плейфера

### Історія

Винайдений **Чарльзом Уітстоном** у 1854 році, але названий на честь його друга **Лорда Плейфера**, який популяризував шифр.

Використовувався британською армією в Другій Бурській війні та Першій світовій.

### Принцип роботи

1. Будуємо матрицю 5×5 з ключовим словом
2. Розбиваємо текст на **біграми** (пари літер)
3. Шифруємо кожну біграму за правилами

### Побудова матриці

```
Ключове слово: PLAYFAIR

┌───┬───┬───┬───┬───┐
│ P │ L │ A │ Y │ F │
├───┼───┼───┼───┼───┤
│ I │ R │ B │ C │ D │
├───┼───┼───┼───┼───┤
│ E │ G │ H │ K │ M │
├───┼───┼───┼───┼───┤
│ N │ O │ Q │ S │ T │
├───┼───┼───┼───┼───┤
│ U │ V │ W │ X │ Z │
└───┴───┴───┴───┴───┘
```

### Підготовка тексту

1. Замінити J на I
2. Розбити на пари
3. Якщо в парі однакові літери — вставити X між ними
4. Якщо непарна кількість — додати X в кінці

```
"HELLO" → "HE" "LX" "LO"  (LL → LX + LO)
"TREE"  → "TR" "EX" "EX"  (EE → EX + EX, але краще TR EE X)

Правильніше: "TREE" → "TR" "EE" → вставляємо X → "TR" "EX" "EX"
```

### Правила шифрування біграм

**Правило 1: Один рядок**

Беремо літери праворуч (з циклом).

```
┌───┬───┬───┬───┬───┐
│ P │ L │ A │ Y │ F │  ← PL → LA
└───┴───┴───┴───┴───┘

P L → L A
Y F → F P (цикл!)
```

**Правило 2: Один стовпець**

Беремо літери знизу (з циклом).

```
│ P │
│ I │  ← PI → IE
│ E │
│ N │
│ U │

P I → I E
N U → U P (цикл!)
```

**Правило 3: Прямокутник**

Беремо літери з протилежних кутів того ж рядка.

```
┌───┬───┬───┬───┬───┐
│ P │ L │ A │ Y │ F │  H-D утворюють прямокутник
├───┼───┼───┼───┼───┤
│ I │ R │ B │ C │[D]│
├───┼───┼───┼───┼───┤
│ E │ G │[H]│ K │ M │
└───┴───┴───┴───┴───┘

H D → K B (протилежні кути)
```

### Приклад шифрування

```
Повідомлення: HELLO WORLD
Ключ: PLAYFAIR

Матриця:
┌───┬───┬───┬───┬───┐
│ P │ L │ A │ Y │ F │
├───┼───┼───┼───┼───┤
│ I │ R │ B │ C │ D │
├───┼───┼───┼───┼───┤
│ E │ G │ H │ K │ M │
├───┼───┼───┼───┼───┤
│ N │ O │ Q │ S │ T │
├───┼───┼───┼───┼───┤
│ U │ V │ W │ X │ Z │
└───┴───┴───┴───┴───┘

Розбиваємо: HE LX LO WO RL DX

HE → (прямокутник) → KG
LX → (прямокутник) → AW
LO → (прямокутник) → AV
WO → (один стовпець) → XV
RL → (один рядок) → BR
DX → (прямокутник) → MU

Шифротекст: KG AW AV XV BR MU
```

### Реалізація на Python

```python
class PlayfairCipher:
    def __init__(self, keyword: str):
        self.matrix = self._build_matrix(keyword)
        self.positions = self._build_positions()

    def _build_matrix(self, keyword: str) -> list:
        """Будує матрицю 5×5."""
        alphabet = ""
        seen = set()

        for char in keyword.upper():
            if char.isalpha() and char not in seen:
                char = 'I' if char == 'J' else char
                seen.add(char)
                alphabet += char

        for char in "ABCDEFGHIKLMNOPQRSTUVWXYZ":
            if char not in seen:
                alphabet += char

        return [list(alphabet[i*5:(i+1)*5]) for i in range(5)]

    def _build_positions(self) -> dict:
        """Створює словник позицій."""
        positions = {}
        for row in range(5):
            for col in range(5):
                char = self.matrix[row][col]
                positions[char] = (row, col)
        return positions

    def _prepare_text(self, text: str) -> list:
        """Готує текст: заміна J, розбиття на біграми."""
        text = text.upper().replace('J', 'I')
        text = ''.join(c for c in text if c.isalpha())

        bigrams = []
        i = 0
        while i < len(text):
            if i + 1 < len(text):
                if text[i] == text[i + 1]:
                    bigrams.append(text[i] + 'X')
                    i += 1
                else:
                    bigrams.append(text[i] + text[i + 1])
                    i += 2
            else:
                bigrams.append(text[i] + 'X')
                i += 1

        return bigrams

    def _encrypt_bigram(self, bigram: str) -> str:
        """Шифрує одну біграму."""
        r1, c1 = self.positions[bigram[0]]
        r2, c2 = self.positions[bigram[1]]

        if r1 == r2:  # Один рядок
            return self.matrix[r1][(c1+1)%5] + self.matrix[r2][(c2+1)%5]
        elif c1 == c2:  # Один стовпець
            return self.matrix[(r1+1)%5][c1] + self.matrix[(r2+1)%5][c2]
        else:  # Прямокутник
            return self.matrix[r1][c2] + self.matrix[r2][c1]

    def _decrypt_bigram(self, bigram: str) -> str:
        """Дешифрує одну біграму."""
        r1, c1 = self.positions[bigram[0]]
        r2, c2 = self.positions[bigram[1]]

        if r1 == r2:  # Один рядок — ліворуч
            return self.matrix[r1][(c1-1)%5] + self.matrix[r2][(c2-1)%5]
        elif c1 == c2:  # Один стовпець — вгору
            return self.matrix[(r1-1)%5][c1] + self.matrix[(r2-1)%5][c2]
        else:  # Прямокутник — так само
            return self.matrix[r1][c2] + self.matrix[r2][c1]

    def encrypt(self, plaintext: str) -> str:
        """Шифрування."""
        bigrams = self._prepare_text(plaintext)
        return ' '.join(self._encrypt_bigram(bg) for bg in bigrams)

    def decrypt(self, ciphertext: str) -> str:
        """Дешифрування."""
        bigrams = ciphertext.replace(' ', '')
        bigrams = [bigrams[i:i+2] for i in range(0, len(bigrams), 2)]
        return ''.join(self._decrypt_bigram(bg) for bg in bigrams)

    def print_matrix(self):
        """Виводить матрицю."""
        for row in self.matrix:
            print(' '.join(row))


# Приклад
cipher = PlayfairCipher("MONARCHY")
cipher.print_matrix()

message = "INSTRUMENTS"
encrypted = cipher.encrypt(message)
print(f"Відкритий текст: {message}")
print(f"Шифротекст: {encrypted}")

decrypted = cipher.decrypt(encrypted)
print(f"Розшифровано: {decrypted}")
```

## Подвійний квадрат Уітстона

### Ідея

Використовуємо **дві** матриці 5×5, розташовані поруч.

```
Матриця 1 (ключ: EXAMPLE)    Матриця 2 (ключ: KEYWORD)

┌───┬───┬───┬───┬───┐       ┌───┬───┬───┬───┬───┐
│ E │ X │ A │ M │ P │       │ K │ E │ Y │ W │ O │
├───┼───┼───┼───┼───┤       ├───┼───┼───┼───┼───┤
│ L │ B │ C │ D │ F │       │ R │ D │ A │ B │ C │
├───┼───┼───┼───┼───┤       ├───┼───┼───┼───┼───┤
│ G │ H │ I │ K │ N │       │ F │ G │ H │ I │ L │
├───┼───┼───┼───┼───┤       ├───┼───┼───┼───┼───┤
│ O │ Q │ R │ S │ T │       │ M │ N │ P │ Q │ S │
├───┼───┼───┼───┼───┤       ├───┼───┼───┼───┼───┤
│ U │ V │ W │ Y │ Z │       │ T │ U │ V │ X │ Z │
└───┴───┴───┴───┴───┘       └───┴───┴───┴───┴───┘
```

### Правила шифрування

1. Перша літера біграми — в лівому квадраті
2. Друга літера — в правому квадраті
3. Формуємо прямокутник і беремо протилежні кути

```
Біграма: HE

H у лівому квадраті: рядок 2, стовпець 1
E у правому квадраті: рядок 0, стовпець 1

     Л                     П
┌───┬───┬───┬───┬───┐ ┌───┬───┬───┬───┬───┐
│ E │ X │ A │ M │ P │ │ K │[E]│ Y │ W │ O │  ← рядок 0
├───┼───┼───┼───┼───┤ ├───┼───┼───┼───┼───┤
│ L │ B │ C │ D │ F │ │ R │ D │ A │ B │ C │
├───┼───┼───┼───┼───┤ ├───┼───┼───┼───┼───┤
│ G │[H]│ I │ K │ N │ │ F │ G │ H │ I │ L │  ← рядок 2
└───┴───┴───┴───┴───┘ └───┴───┴───┴───┴───┘

Шифр: [X, G] (протилежні кути)
HE → XG
```

### Переваги подвійного квадрата

1. **Більший простір ключів**: два незалежних ключових слова
2. **Стійкіший до частотного аналізу**: біграми розподіляються рівномірніше
3. **Немає проблеми однакових літер**: правила працюють для будь-яких пар

### Реалізація

```python
class TwoSquareCipher:
    def __init__(self, keyword1: str, keyword2: str):
        self.left = self._build_matrix(keyword1)
        self.right = self._build_matrix(keyword2)
        self.left_pos = self._positions(self.left)
        self.right_pos = self._positions(self.right)

    def _build_matrix(self, keyword: str) -> list:
        """Будує матрицю 5×5."""
        alphabet = ""
        seen = set()

        for char in keyword.upper():
            if char.isalpha() and char not in seen:
                char = 'I' if char == 'J' else char
                seen.add(char)
                alphabet += char

        for char in "ABCDEFGHIKLMNOPQRSTUVWXYZ":
            if char not in seen:
                alphabet += char

        return [list(alphabet[i*5:(i+1)*5]) for i in range(5)]

    def _positions(self, matrix: list) -> dict:
        """Створює словник позицій."""
        pos = {}
        for row in range(5):
            for col in range(5):
                pos[matrix[row][col]] = (row, col)
        return pos

    def encrypt(self, plaintext: str) -> str:
        """Шифрування подвійним квадратом."""
        text = plaintext.upper().replace('J', 'I')
        text = ''.join(c for c in text if c.isalpha())
        if len(text) % 2:
            text += 'X'

        result = []
        for i in range(0, len(text), 2):
            a, b = text[i], text[i+1]

            r1, c1 = self.left_pos[a]   # Перша літера в лівому
            r2, c2 = self.right_pos[b]  # Друга в правому

            # Беремо протилежні кути
            new_a = self.left[r2][c1]   # Ліва матриця, рядок другої
            new_b = self.right[r1][c2]  # Права матриця, рядок першої

            result.append(new_a + new_b)

        return ' '.join(result)

    def decrypt(self, ciphertext: str) -> str:
        """Дешифрування — та сама операція."""
        return self.encrypt(ciphertext.replace(' ', ''))


# Приклад
cipher = TwoSquareCipher("EXAMPLE", "KEYWORD")
message = "HELLO WORLD"
encrypted = cipher.encrypt(message)
print(f"Шифротекст: {encrypted}")

decrypted = cipher.decrypt(encrypted)
print(f"Розшифровано: {decrypted}")
```

## Криптоаналіз шифру Плейфера

1. **Аналіз біграм**: деякі біграми зустрічаються частіше (TH, HE, AN)
2. **Реверс**: якщо AB → XY, то BA → YX (симетрія прямокутника)
3. **Знання ключа**: якщо відоме слово з тексту, можна відновити матрицю

Історичний факт: шифр Плейфера був зламаний криптоаналітиками під час Першої світової війни.

```python
# Створення матриці Плейфера
def create_playfair_matrix(keyword):
    alphabet = ""
    for c in keyword.upper() + "ABCDEFGHIKLMNOPQRSTUVWXYZ":
        if c not in alphabet and c != 'J':
            alphabet += c
    return [list(alphabet[i*5:(i+1)*5]) for i in range(5)]

# Знаходження позиції в матриці
def find_position(matrix, char):
    for r, row in enumerate(matrix):
        if char in row:
            return r, row.index(char)
    return None
```

## ❓ Питання для самоперевірки

**1. Чому в квадраті Полібія об'єднуються I та J?**
> Щоб вмістити 26 літер у квадрат 5×5 (25 клітинок). I та J рідко розрізняються в контексті.

**2. Як шифр Плейфера обробляє подвійні літери в біграмі (наприклад, "LL")?**
> Між ними вставляється X: "LL" → "LX" + "LO" (або інша біграма з наступною літерою).

**3. Яка перевага подвійного квадрата над шифром Плейфера?**
> Більший простір ключів ((25!)² vs 25!), немає проблеми з однаковими літерами, рівномірніший розподіл біграм.

**4. Чому шифр Плейфера стійкіший за моноалфавітний?**
> Шифрує біграми (676 варіантів) замість окремих літер (26). Частотний аналіз складніший.

**5. Як визначити, що текст зашифровано Плейфером?**
> Відсутність літери J, текст парної довжини, характерні патерни біграм (AB→XY означає BA→YX).
