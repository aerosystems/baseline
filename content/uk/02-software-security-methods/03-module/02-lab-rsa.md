## Теоретичні відомості

### 1 Історія та концепція

RSA (Rivest-Shamir-Adleman) — перший практичний алгоритм асиметричного шифрування, опублікований у 1977 році. Він базується на обчислювальній складності факторизації великих чисел.

```
┌───────────────────────────────────────────────────────────────────────┐
│                    АСИМЕТРИЧНЕ ШИФРУВАННЯ                             │
├───────────────────────────────────────────────────────────────────────┤
│                                                                       │
│  СИМЕТРИЧНЕ:           АСИМЕТРИЧНЕ (RSA):                             │
│                                                                       │
│  Один ключ K           Два ключі: (e, n) та (d, n)                    │
│  ─────────────         ───────────────────────────                    │
│  Encrypt(M, K) → C     Encrypt(M, e, n) → C                           │
│  Decrypt(C, K) → M     Decrypt(C, d, n) → M                           │
│                                                                       │
│  Проблема:             Перевага:                                      │
│  Як передати K?        Відкритий ключ можна публікувати               │
│                                                                       │
└───────────────────────────────────────────────────────────────────────┘
```
### 2 Математичні основи

**Функція Ейлера φ(n):**

- Кількість чисел від 1 до n, взаємно простих з n
- Для простого p: φ(p) = p - 1
- Для добутку простих: φ(p·q) = (p-1)(q-1)

**Теорема Ейлера:**

- Якщо gcd(a, n) = 1, то a^φ(n) ≡ 1 (mod n)

**Наслідок для RSA:**

- Якщо e·d ≡ 1 (mod φ(n)), то (M<sup>e)</sup>d ≡ M (mod n)

### 3 Алгоритм RSA

```
┌───────────────────────────────────────────────────────────────────────┐
│                    АЛГОРИТМ RSA                                       │
├───────────────────────────────────────────────────────────────────────┤
│                                                                       │
│  ГЕНЕРАЦІЯ КЛЮЧІВ:                                                    │
│  ┌─────────────────────────────────────────────────────────────────┐  │
│  │ 1. Вибрати два великих простих числа p і q                      │  │
│  │ 2. Обчислити n = p × q                                          │  │
│  │ 3. Обчислити φ(n) = (p-1) × (q-1)                               │  │
│  │ 4. Вибрати e таке, що 1 < e < φ(n) і gcd(e, φ(n)) = 1           │  │
│  │    (часто e = 65537 = 2^16 + 1)                                 │  │
│  │ 5. Обчислити d = e⁻¹ mod φ(n)                                   │  │
│  │                                                                 │  │
│  │ Відкритий ключ: (e, n)                                          │  │
│  │ Закритий ключ: (d, n)                                           │  │
│  └─────────────────────────────────────────────────────────────────┘  │
│                                                                       │
│  ШИФРУВАННЯ:                                                          │
│  ┌─────────────────────────────────────────────────────────────────┐  │
│  │ C = M^e mod n                                                   │  │
│  │ (використовується відкритий ключ отримувача)                    │  │
│  └─────────────────────────────────────────────────────────────────┘  │
│                                                                       │
│  ДЕШИФРУВАННЯ:                                                        │
│  ┌─────────────────────────────────────────────────────────────────┐  │
│  │ M = C^d mod n                                                   │  │
│  │ (використовується закритий ключ)                                │  │
│  └─────────────────────────────────────────────────────────────────┘  │
│                                                                       │
└───────────────────────────────────────────────────────────────────────┘
```

```
  d = 2753 (17 × 2753 = 46801 = 15 × 3120 + 1)

Відкритий ключ: (17, 3233)
Закритий ключ: (2753, 3233)

Шифрування M = 65 (літера 'A'):
  C = 65^17 mod 3233 = 2790

Дешифрування C = 2790:
  M = 2790^2753 mod 3233 = 65
```
### 5 Швидке модульне піднесення до степеня

Прямий підхід a^b потребує b множень — занадто повільно для великих чисел.

**Метод "square-and-multiply" (бінарне піднесення):**

```
Для обчислення a^b mod n:

1. Представити b у двійковому вигляді: b = (b_k ... b_1 b_0)₂
2. result = 1
3. base = a
4. Для кожного біта b_i (від молодшого до старшого):
   - Якщо b_i = 1: result = (result × base) mod n
   - base = (base × base) mod n
5. Повернути result

Приклад: 3^13 mod 7
13 = 1101₂
  i=0: b=1, result = 1×3 = 3, base = 3²=9 ≡ 2 (mod 7)
  i=1: b=0, result = 3,      base = 2²=4 (mod 7)
  i=2: b=1, result = 3×4 = 12 ≡ 5 (mod 7), base = 4²=16 ≡ 2 (mod 7)
  i=3: b=1, result = 5×2 = 10 ≡ 3 (mod 7)
Відповідь: 3^13 ≡ 3 (mod 7)
```
### 6 Обчислення оберненого за модулем

Для знаходження d = e⁻¹ mod φ(n) використовується **розширений алгоритм Евкліда**.

```
Розширений алгоритм Евкліда:
gcd(a, b) = a×x + b×y

Якщо gcd(e, φ(n)) = 1, то:
e×x + φ(n)×y = 1
e×x ≡ 1 (mod φ(n))
Отже, d = x mod φ(n)
```

### Крок 1. Допоміжні функції (Python)

```python
from typing import Tuple
import random

def gcd(a: int, b: int) -> int:
    """Найбільший спільний дільник (алгоритм Евкліда)."""
    while b:
        a, b = b, a % b
    return a

def extended_gcd(a: int, b: int) -> Tuple[int, int, int]:
    """
    Розширений алгоритм Евкліда.
    Повертає (gcd, x, y) такі, що a*x + b*y = gcd
    """
    if a == 0:
        return b, 0, 1

    gcd_val, x1, y1 = extended_gcd(b % a, a)
    x = y1 - (b // a) * x1
    y = x1

    return gcd_val, x, y

def mod_inverse(e: int, phi: int) -> int:
    """
    Обчислює мультиплікативний обернений: d = e^(-1) mod phi
    """
    gcd_val, x, _ = extended_gcd(e, phi)

    if gcd_val != 1:
        raise ValueError(f"Обернений не існує: gcd({e}, {phi}) = {gcd_val}")

    return x % phi

def mod_pow(base: int, exp: int, mod: int) -> int:
    """
    Швидке модульне піднесення до степеня: base^exp mod mod
    Метод square-and-multiply
    """
    result = 1
    base = base % mod

    while exp > 0:
        # Якщо exp непарний, множимо result на base
        if exp & 1:
            result = (result * base) % mod

        # exp стає парним
        exp >>= 1
        base = (base * base) % mod

    return result

def is_prime(n: int, k: int = 10) -> bool:
    """
    Тест простоти Міллера-Рабіна.
    k — кількість раундів тестування.
    """
    if n < 2:
        return False
    if n == 2 or n == 3:
        return True
    if n % 2 == 0:
        return False

    # Представляємо n-1 як 2^r * d
    r, d = 0, n - 1
    while d % 2 == 0:
        r += 1
        d //= 2

    # Тестуємо k разів
    for _ in range(k):
        a = random.randrange(2, n - 1)
        x = mod_pow(a, d, n)

        if x == 1 or x == n - 1:
            continue

        for _ in range(r - 1):
            x = mod_pow(x, 2, n)
            if x == n - 1:
                break
        else:
            return False

    return True

def generate_prime(bits: int) -> int:
    """Генерує випадкове просте число заданої розрядності."""
    while True:
        # Генеруємо непарне число
        candidate = random.getrandbits(bits) | (1 << bits - 1) | 1
        if is_prime(candidate):
            return candidate
```
### Крок 2. Генерація ключів

```python
class RSA:
    """Реалізація алгоритму RSA."""

    def __init__(self, p: int = None, q: int = None, bits: int = 512):
        """
        Ініціалізація з заданими простими числами або генерація нових.
        """
        if p and q:
            self.p = p
            self.q = q
        else:
            self.p = generate_prime(bits // 2)
            self.q = generate_prime(bits // 2)

        self.n = self.p * self.q
        self.phi = (self.p - 1) * (self.q - 1)

        # Вибір e (зазвичай 65537)
        self.e = 65537
        while gcd(self.e, self.phi) != 1:
            self.e += 2

        # Обчислення d
        self.d = mod_inverse(self.e, self.phi)

    def get_public_key(self) -> Tuple[int, int]:
        """Повертає відкритий ключ (e, n)."""
        return (self.e, self.n)

    def get_private_key(self) -> Tuple[int, int]:
        """Повертає закритий ключ (d, n)."""
        return (self.d, self.n)

    def encrypt(self, plaintext: int) -> int:
        """
        Шифрує повідомлення: C = M^e mod n
        """
        if plaintext >= self.n:
            raise ValueError(f"Повідомлення {plaintext} >= n={self.n}")
        return mod_pow(plaintext, self.e, self.n)

    def decrypt(self, ciphertext: int) -> int:
        """
        Дешифрує повідомлення: M = C^d mod n
        """
        return mod_pow(ciphertext, self.d, self.n)

    def encrypt_with_public_key(self, plaintext: int, e: int, n: int) -> int:
        """Шифрує з чужим відкритим ключем."""
        return mod_pow(plaintext, e, n)
```
### Крок 3. Шифрування тексту

```python
def text_to_number(text: str) -> int:
    """Конвертує текст у число."""
    return int.from_bytes(text.encode('utf-8'), 'big')

def number_to_text(number: int) -> str:
    """Конвертує число назад у текст."""
    length = (number.bit_length() + 7) // 8
    return number.to_bytes(length, 'big').decode('utf-8')

def encrypt_text(rsa: RSA, text: str) -> int:
    """Шифрує текстове повідомлення."""
    m = text_to_number(text)
    if m >= rsa.n:
        raise ValueError("Текст занадто довгий для цього ключа")
    return rsa.encrypt(m)

def decrypt_text(rsa: RSA, ciphertext: int) -> str:
    """Дешифрує повідомлення у текст."""
    m = rsa.decrypt(ciphertext)
    return number_to_text(m)
```

```python
def demo():
    print("=" * 60)
    print("ДЕМОНСТРАЦІЯ АЛГОРИТМУ RSA")
    print("=" * 60)

    # Приклад з малими простими (для демонстрації)
    p, q = 61, 53
    rsa = RSA(p, q)

    print(f"\n1. ГЕНЕРАЦІЯ КЛЮЧІВ")
    print(f"   p = {p}")
    print(f"   q = {q}")
    print(f"   n = p × q = {rsa.n}")
    print(f"   φ(n) = (p-1)(q-1) = {rsa.phi}")
    print(f"   e = {rsa.e}")
    print(f"   d = {rsa.d}")
    print(f"\n   Відкритий ключ: ({rsa.e}, {rsa.n})")
    print(f"   Закритий ключ: ({rsa.d}, {rsa.n})")

    # Перевірка: e * d ≡ 1 (mod φ(n))
    print(f"\n   Перевірка: e × d mod φ(n) = {(rsa.e * rsa.d) % rsa.phi}")

    # Шифрування числа
    print(f"\n2. ШИФРУВАННЯ ЧИСЛА")
    M = 65  # ASCII код 'A'
    print(f"   Повідомлення M = {M} (символ '{chr(M)}')")

    C = rsa.encrypt(M)
    print(f"   Шифротекст C = M^e mod n = {M}^{rsa.e} mod {rsa.n} = {C}")

    # Дешифрування
    print(f"\n3. ДЕШИФРУВАННЯ")
    M_dec = rsa.decrypt(C)
    print(f"   Розшифроване M = C^d mod n = {C}^{rsa.d} mod {rsa.n} = {M_dec}")
    print(f"   Символ: '{chr(M_dec)}'")

    if M == M_dec:
        print(f"\n   ✓ Тест пройдено: розшифроване = оригінал")
    else:
        print(f"\n   ✗ Помилка!")

    # Шифрування тексту (з більшим ключем)
    print(f"\n4. ШИФРУВАННЯ ТЕКСТУ (більший ключ)")
    rsa_big = RSA(p=104729, q=104743)  # Більші прості

    text = "Hello"
    print(f"   Текст: \"{text}\"")
    print(f"   n = {rsa_big.n}")

    ciphertext = encrypt_text(rsa_big, text)
    print(f"   Шифротекст: {ciphertext}")

    decrypted = decrypt_text(rsa_big, ciphertext)
    print(f"   Розшифровано: \"{decrypted}\"")

    # Демонстрація асиметричності
    print(f"\n5. АСИМЕТРИЧНІСТЬ")
    print(f"   Боб публікує свій відкритий ключ: ({rsa.e}, {rsa.n})")
    print(f"   Аліса шифрує повідомлення M=42 ключем Боба:")
    C_alice = rsa.encrypt_with_public_key(42, rsa.e, rsa.n)
    print(f"   C = 42^{rsa.e} mod {rsa.n} = {C_alice}")
    print(f"   Тільки Боб (з ключем d={rsa.d}) може розшифрувати:")
    M_bob = rsa.decrypt(C_alice)
    print(f"   M = {C_alice}^{rsa.d} mod {rsa.n} = {M_bob}")

if __name__ == "__main__":
    demo()
```

8. Чому RSA повільніший за симетричні шифри?
9. Як RSA використовується разом із симетричним шифруванням (гібридне)?
10. Що станеться, якщо p = q?

## Cheat Sheet

```
┌───────────────────────────────────────────────────────────────────────┐
│                    ШПАРГАЛКА: RSA                                     │
├───────────────────────────────────────────────────────────────────────┤
│                                                                       │
│  ГЕНЕРАЦІЯ КЛЮЧІВ:                                                    │
│  ┌─────────────────────────────────────────────────────────────────┐  │
│  │ n = p × q                                                       │  │
│  │ φ(n) = (p-1)(q-1)                                               │  │
│  │ e: gcd(e, φ(n)) = 1                                             │  │
│  │ d = e⁻¹ mod φ(n)                                                │  │
│  │                                                                 │  │
│  │ Публічний: (e, n)   Приватний: (d, n)                           │  │
│  └─────────────────────────────────────────────────────────────────┘  │
│                                                                       │
│  ШИФРУВАННЯ/ДЕШИФРУВАННЯ:                                             │
│  ┌─────────────────────────────────────────────────────────────────┐  │
│  │ Encrypt: C = M^e mod n                                          │  │
│  │ Decrypt: M = C^d mod n                                          │  │
│  └─────────────────────────────────────────────────────────────────┘  │
│                                                                       │
│  ШВИДКЕ ПІДНЕСЕННЯ (a^b mod n):                                       │
│  ┌─────────────────────────────────────────────────────────────────┐  │
│  │ result = 1                                                      │  │
│  │ while b > 0:                                                    │  │
│  │   if b & 1: result = (result × a) mod n                         │  │
│  │   a = (a × a) mod n                                             │  │
│  │   b >>= 1                                                       │  │
│  └─────────────────────────────────────────────────────────────────┘  │
│                                                                       │
│  ТИПОВІ ЗНАЧЕННЯ:                                                     │
│  ┌─────────────────────────────────────────────────────────────────┐  │
│  │ e = 65537 (2^16 + 1)  — стандартне                              │  │
│  │ Ключ: 2048 біт (мінімум), 4096 біт (рекомендовано)              │  │
│  └─────────────────────────────────────────────────────────────────┘  │
│                                                                       │
└───────────────────────────────────────────────────────────────────────┘
```
