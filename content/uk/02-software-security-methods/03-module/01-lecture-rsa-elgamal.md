## Революція 1976-1977 років

У 1976 році Whitfield Diffie та Martin Hellman опублікували статтю "New Directions in Cryptography", де запропонували ідею **криптографії з відкритим ключем**.

У 1977 році Ron Rivest, Adi Shamir та Leonard Adleman реалізували цю ідею в алгоритмі **RSA** — першій практичній асиметричній криптосистемі.

```
┌─────────────────────────────────────────────────────────────────────┐
│                    ХРОНОЛОГІЯ                                       │
│                                                                     │
│  1976: Diffie-Hellman — ідея асиметричної криптографії             │
│    │                                                                │
│    ▼                                                                │
│  1977: RSA — перша реалізація                                       │
│    │                                                                │
│    ▼                                                                │
│  1985: ElGamal — альтернатива на дискретному логарифмі             │
│    │                                                                │
│    ▼                                                                │
│  1985: ECC — еліптичні криві (Miller, Koblitz)                     │
│    │                                                                │
│    ▼                                                                │
│  2000+: RSA-2048 стає стандартом                                   │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

## Криптосистема RSA

### Математична основа

RSA базується на складності **факторизації** великих чисел:

```
Легко:   p × q = n    (множення)
         17 × 23 = 391

Важко:   n → p, q     (факторизація)
         391 = ? × ?
```

Для малих чисел — тривіально. Для чисел з 600+ цифр — практично неможливо.

### Генерація ключів RSA

```
┌─────────────────────────────────────────────────────────────────────┐
│                    ГЕНЕРАЦІЯ КЛЮЧІВ RSA                             │
│                                                                     │
│  Крок 1: Обираємо два великих простих числа p та q                 │
│          (типово 1024+ біт кожне)                                   │
│                                                                     │
│  Крок 2: Обчислюємо n = p × q                                       │
│          (модуль, частина публічного ключа)                         │
│                                                                     │
│  Крок 3: Обчислюємо φ(n) = (p-1)(q-1)                               │
│          (функція Ейлера)                                           │
│                                                                     │
│  Крок 4: Обираємо e таке, що:                                       │
│          • 1 < e < φ(n)                                             │
│          • gcd(e, φ(n)) = 1                                         │
│          (типово e = 65537 = 2¹⁶ + 1)                               │
│                                                                     │
│  Крок 5: Обчислюємо d = e⁻¹ mod φ(n)                                │
│          (d × e ≡ 1 (mod φ(n)))                                     │
│                                                                     │
│  Результат:                                                         │
│  • Публічний ключ:  (n, e)                                          │
│  • Приватний ключ:  (n, d)   [або (p, q, d)]                        │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

### Приклад з малими числами

```
Крок 1: p = 61, q = 53

Крок 2: n = 61 × 53 = 3233

Крок 3: φ(n) = (61-1)(53-1) = 60 × 52 = 3120

Крок 4: Обираємо e = 17 (gcd(17, 3120) = 1) ✓

Крок 5: Знаходимо d: 17 × d ≡ 1 (mod 3120)
        d = 2753 (бо 17 × 2753 = 46801 = 15 × 3120 + 1)

Публічний ключ:  (3233, 17)
Приватний ключ:  (3233, 2753)
```

### Шифрування та дешифрування

```
┌─────────────────────────────────────────────────────────────────────┐
│                    ШИФРУВАННЯ RSA                                   │
│                                                                     │
│  Шифрування (публічним ключем):                                     │
│                                                                     │
│      C = Mᵉ mod n                                                   │
│                                                                     │
│  Дешифрування (приватним ключем):                                   │
│                                                                     │
│      M = Cᵈ mod n                                                   │
│                                                                     │
│  Чому це працює?                                                    │
│                                                                     │
│      Cᵈ = (Mᵉ)ᵈ = Mᵉᵈ mod n                                         │
│                                                                     │
│      За теоремою Ейлера: Mᵉᵈ ≡ M (mod n)                            │
│      (бо e×d ≡ 1 (mod φ(n)))                                        │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

**Приклад:**

```
Повідомлення M = 123
Публічний ключ: (n=3233, e=17)
Приватний ключ: (n=3233, d=2753)

Шифрування:
C = 123¹⁷ mod 3233 = 855

Дешифрування:
M = 855²⁷⁵³ mod 3233 = 123 ✓
```

### Алгоритм швидкого піднесення до степеня

Для великих показників використовують **бінарне піднесення** (square-and-multiply):

```python
def fast_power(base: int, exp: int, mod: int) -> int:
    """Швидке піднесення до степеня за модулем."""
    result = 1
    base = base % mod

    while exp > 0:
        # Якщо exp непарне — множимо на base
        if exp % 2 == 1:
            result = (result * base) % mod

        # exp = exp // 2
        exp = exp >> 1
        # base = base²
        base = (base * base) % mod

    return result


# Приклад: 123¹⁷ mod 3233
# 17 = 10001₂
# 123¹⁷ = 123¹⁶ × 123¹ = (123⁸)² × 123
```

### Реалізація RSA на Python

```python
import random
from math import gcd


def is_prime(n: int, k: int = 10) -> bool:
    """Тест Міллера-Рабіна на простоту."""
    if n < 2:
        return False
    if n == 2 or n == 3:
        return True
    if n % 2 == 0:
        return False

    # n - 1 = 2^r × d
    r, d = 0, n - 1
    while d % 2 == 0:
        r += 1
        d //= 2

    # k раундів тестування
    for _ in range(k):
        a = random.randrange(2, n - 1)
        x = pow(a, d, n)

        if x == 1 or x == n - 1:
            continue

        for _ in range(r - 1):
            x = pow(x, 2, n)
            if x == n - 1:
                break
        else:
            return False

    return True


def generate_prime(bits: int) -> int:
    """Генерує випадкове просте число заданої бітової довжини."""
    while True:
        p = random.getrandbits(bits) | (1 << bits - 1) | 1
        if is_prime(p):
            return p


def mod_inverse(e: int, phi: int) -> int:
    """Обчислює e⁻¹ mod phi (розширений алгоритм Евкліда)."""
    def extended_gcd(a, b):
        if a == 0:
            return b, 0, 1
        gcd, x1, y1 = extended_gcd(b % a, a)
        x = y1 - (b // a) * x1
        y = x1
        return gcd, x, y

    _, x, _ = extended_gcd(e % phi, phi)
    return (x % phi + phi) % phi


class RSA:
    def __init__(self, bits: int = 1024):
        # Генеруємо два простих числа
        p = generate_prime(bits // 2)
        q = generate_prime(bits // 2)

        self.n = p * q
        phi = (p - 1) * (q - 1)

        # Публічна експонента
        self.e = 65537

        # Приватна експонента
        self.d = mod_inverse(self.e, phi)

    def encrypt(self, m: int) -> int:
        """Шифрування."""
        return pow(m, self.e, self.n)

    def decrypt(self, c: int) -> int:
        """Дешифрування."""
        return pow(c, self.d, self.n)

    def public_key(self) -> tuple:
        return (self.n, self.e)

    def private_key(self) -> tuple:
        return (self.n, self.d)


# Приклад використання
rsa = RSA(bits=512)  # Для демонстрації, у продакшені 2048+
print(f"Публічний ключ: n має {rsa.n.bit_length()} біт")

message = 42
encrypted = rsa.encrypt(message)
decrypted = rsa.decrypt(encrypted)

print(f"Повідомлення: {message}")
print(f"Зашифровано: {encrypted}")
print(f"Розшифровано: {decrypted}")
```

### Безпека RSA

**Рекомендовані розміри ключів:**

| Рік | Мінімум | Рекомендовано |
|-----|---------|---------------|
| 2020 | 2048 біт | 3072 біт |
| 2030+ | 3072 біт | 4096 біт |

**Атаки на RSA:**

1. **Факторизація n** — найпряміша атака
2. **Малий публічний показник** — якщо e мале і M мале, C = Mᵉ може не "обернутися" за модулем
3. **Спільний модуль** — не використовуйте один n для різних користувачів
4. **Timing attacks** — час дешифрування видає інформацію про d

## Криптосистема Ель-Гамаля

### Математична основа

Ель-Гамаль (Taher Elgamal, 1985) базується на складності **дискретного логарифму**:

```
Легко:   y = gˣ mod p    (піднесення до степеня)

Важко:   x = log_g(y) mod p    (дискретний логарифм)
         Знайти x, знаючи y, g, p
```

### Генерація ключів

```
┌─────────────────────────────────────────────────────────────────────┐
│                    ГЕНЕРАЦІЯ КЛЮЧІВ ЕЛЬ-ГАМАЛЯ                      │
│                                                                     │
│  Крок 1: Обираємо велике просте p та генератор g групи Z*_p        │
│          (g — примітивний корінь за модулем p)                      │
│                                                                     │
│  Крок 2: Обираємо випадкове x, де 1 < x < p-1                       │
│          (приватний ключ)                                           │
│                                                                     │
│  Крок 3: Обчислюємо y = gˣ mod p                                    │
│          (публічний ключ)                                           │
│                                                                     │
│  Результат:                                                         │
│  • Публічний ключ:  (p, g, y)                                       │
│  • Приватний ключ:  x                                               │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

### Шифрування

```
┌─────────────────────────────────────────────────────────────────────┐
│                    ШИФРУВАННЯ ЕЛЬ-ГАМАЛЯ                            │
│                                                                     │
│  Вхід: повідомлення M (число < p)                                   │
│                                                                     │
│  Крок 1: Обираємо випадкове k, де 1 < k < p-1                       │
│          (сесійний ключ, новий для кожного повідомлення!)           │
│                                                                     │
│  Крок 2: Обчислюємо:                                                │
│          a = gᵏ mod p                                               │
│          b = M × yᵏ mod p                                           │
│                                                                     │
│  Шифротекст: (a, b)                                                 │
│                                                                     │
│  Зверніть увагу: шифротекст удвічі більший за відкритий текст!     │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

### Дешифрування

```
┌─────────────────────────────────────────────────────────────────────┐
│                    ДЕШИФРУВАННЯ ЕЛЬ-ГАМАЛЯ                          │
│                                                                     │
│  Вхід: шифротекст (a, b)                                            │
│                                                                     │
│  Обчислюємо:                                                        │
│          M = b × a⁻ˣ mod p                                          │
│            = b × (aˣ)⁻¹ mod p                                       │
│                                                                     │
│  Чому це працює?                                                    │
│                                                                     │
│          b × a⁻ˣ = (M × yᵏ) × (gᵏ)⁻ˣ                                │
│                  = M × (gˣ)ᵏ × g⁻ᵏˣ                                 │
│                  = M × gᵏˣ × g⁻ᵏˣ                                   │
│                  = M                                                │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

### Приклад

```
Параметри: p = 23, g = 5

Генерація ключів:
  x = 6 (приватний)
  y = 5⁶ mod 23 = 15625 mod 23 = 8 (публічний)

Публічний ключ: (23, 5, 8)
Приватний ключ: 6

Шифрування M = 7:
  k = 3 (випадковий)
  a = 5³ mod 23 = 125 mod 23 = 10
  b = 7 × 8³ mod 23 = 7 × 512 mod 23 = 3584 mod 23 = 17

Шифротекст: (10, 17)

Дешифрування:
  a⁻ˣ = 10⁻⁶ mod 23
  aˣ = 10⁶ mod 23 = 1000000 mod 23 = 16
  (aˣ)⁻¹ mod 23: 16 × ? ≡ 1 (mod 23) → 16 × 13 = 208 = 9×23 + 1, отже 13

  M = 17 × 13 mod 23 = 221 mod 23 = 7 ✓
```

### Реалізація Ель-Гамаля

```python
import random


class ElGamal:
    def __init__(self, p: int, g: int):
        self.p = p
        self.g = g
        # Приватний ключ
        self.x = random.randint(2, p - 2)
        # Публічний ключ
        self.y = pow(g, self.x, p)

    def public_key(self) -> tuple:
        return (self.p, self.g, self.y)

    def encrypt(self, m: int) -> tuple:
        """Шифрування."""
        k = random.randint(2, self.p - 2)
        a = pow(self.g, k, self.p)
        b = (m * pow(self.y, k, self.p)) % self.p
        return (a, b)

    def decrypt(self, a: int, b: int) -> int:
        """Дешифрування."""
        # a^(-x) = (a^x)^(-1)
        s = pow(a, self.x, self.p)
        s_inv = pow(s, self.p - 2, self.p)  # Мала теорема Ферма
        m = (b * s_inv) % self.p
        return m


# Приклад (малі числа для демонстрації)
elgamal = ElGamal(p=467, g=2)
print(f"Публічний ключ: {elgamal.public_key()}")

message = 123
a, b = elgamal.encrypt(message)
print(f"Шифротекст: ({a}, {b})")

decrypted = elgamal.decrypt(a, b)
print(f"Розшифровано: {decrypted}")
```

### OpenSSL команди

```bash
# Генерація RSA ключа
openssl genrsa -out private.pem 2048

# Витяг публічного ключа

openssl rsa -in private.pem -text -noout

# Дешифрування приватним ключем
openssl rsautl -decrypt -inkey private.pem -in encrypted.bin -out decrypted.txt

# Перевірка підпису
openssl dgst -sha256 -verify public.pem -signature signature.bin document.txt

# Генерація RSA-4096 для продакшену
openssl genrsa -out private_4096.pem 4096
```

## ❓ Питання для самоперевірки

### 1. Чому e = 65537 є стандартним вибором для публічної експоненти RSA?

**Відповідь:** 65537 = 2¹⁶ + 1 — це число Ферма, яке має лише два біти "1" у бінарному представленні (10000000000000001). Це робить операцію піднесення до степеня дуже швидкою (лише 17 множень замість тисяч). Також 65537 достатньо велике, щоб уникнути атак на малий публічний показник.

### 2. Що станеться, якщо p та q будуть занадто близькими?

**Відповідь:** Якщо p ≈ q, то n ≈ p², і √n ≈ p. Атака Ферма зможе швидко факторизувати n, починаючи з √n і перевіряючи сусідні числа. Рекомендація: |p - q| > 2^(n/2 - 100), де n — бітова довжина модуля.

### 3. Чому в Ель-Гамаля шифротекст удвічі більший за відкритий текст?

**Відповідь:** Шифротекст Ель-Гамаля складається з пари (a, b), де a = gᵏ mod p та b = M × yᵏ mod p. Кожен компонент має розмір, рівний розміру модуля p, тому загальний розмір шифротексту — 2 × розмір повідомлення.

### 4. Чому не можна повторно використовувати k в Ель-Гамаля?

**Відповідь:** Якщо використати однакове k для двох повідомлень M₁ та M₂, отримаємо однакове a = gᵏ. Знаючи b₁ = M₁ × yᵏ та b₂ = M₂ × yᵏ, зловмисник може обчислити M₁/M₂ = b₁/b₂, що дає інформацію про відкритий текст.

### 5. Яка різниця між RSA-OAEP та RSA-PKCS#1 v1.5?

**Відповідь:** PKCS#1 v1.5 — детерміністичний padding, вразливий до атак Bleichenbacher. OAEP (Optimal Asymmetric Encryption Padding) — ймовірнісний padding з доведеною безпекою. Для нових систем завжди використовуйте OAEP.

## Підсумок

| Термін | Визначення |
|--------|------------|
| **RSA** | Криптосистема на факторизації |
| **Ель-Гамаль** | Криптосистема на дискретному логарифмі |
| **φ(n)** | Функція Ейлера: кількість чисел < n, взаємно простих з n |
| **e, d** | Публічна та приватна експоненти RSA |
| **Сесійний ключ k** | Випадкове число в Ель-Гамаля |

**Ключові формули:**
- RSA шифрування: `C = Mᵉ mod n`
- RSA дешифрування: `M = Cᵈ mod n`
- Ель-Гамаль: `(a, b) = (gᵏ, M × yᵏ)`

На наступній лекції розглянемо електронний цифровий підпис та хеш-функції.
