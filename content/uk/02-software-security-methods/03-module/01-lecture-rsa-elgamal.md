## Революція 1976-1977 років

У 1976 році Whitfield Diffie та Martin Hellman опублікували статтю "New Directions in Cryptography", де запропонували ідею **криптографії з відкритим ключем**.

У 1977 році Ron Rivest, Adi Shamir та Leonard Adleman реалізували цю ідею в алгоритмі **RSA** — першій практичній асиметричній криптосистемі.

```
┌─────────────────────────────────────────────────────────────────────┐
│                    ХРОНОЛОГІЯ                                       │
│                                                                     │
│  1976: Diffie-Hellman — ідея асиметричної криптографії              │
│    │                                                                │
│    ▼                                                                │
│  1977: RSA — перша реалізація                                       │
│    │                                                                │
│    ▼                                                                │
│  1985: ElGamal — альтернатива на дискретному логарифмі              │
│    │                                                                │
│    ▼                                                                │
│  1985: ECC — еліптичні криві (Miller, Koblitz)                      │
│    │                                                                │
│    ▼                                                                │
│  2000+: RSA-2048 стає стандартом                                    │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

## Криптосистема RSA

### Математична основа

RSA базується на складності **факторизації** великих чисел:

```
Легко:   p × q = n    (множення)
         17 × 23 = 391

Важко:   n → p, q     (факторизація)
         391 = ? × ?
```

Для малих чисел — тривіально. Для чисел з 600+ цифр — практично неможливо.

### Генерація ключів RSA

```
┌─────────────────────────────────────────────────────────────────────┐
│                    ГЕНЕРАЦІЯ КЛЮЧІВ RSA                             │
│                                                                     │
│  Крок 1: Обираємо два великих простих числа p та q                  │
│          (типово 1024+ біт кожне)                                   │
│                                                                     │
│  Крок 2: Обчислюємо n = p × q                                       │
│          (модуль, частина публічного ключа)                         │
│                                                                     │
│  Крок 3: Обчислюємо φ(n) = (p-1)(q-1)                               │
│          (функція Ейлера)                                           │
│                                                                     │
│  Крок 4: Обираємо e таке, що:                                       │
│          • 1 < e < φ(n)                                             │
│          • gcd(e, φ(n)) = 1                                         │
│          (типово e = 65537 = 2¹⁶ + 1)                               │
│                                                                     │
│  Крок 5: Обчислюємо d = e⁻¹ mod φ(n)                                │
│          (d × e ≡ 1 (mod φ(n)))                                     │
│                                                                     │
│  Результат:                                                         │
│  • Публічний ключ:  (n, e)                                          │
│  • Приватний ключ:  (n, d)   [або (p, q, d)]                        │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

### Приклад з малими числами

```
Крок 1: p = 61, q = 53

Крок 2: n = 61 × 53 = 3233

Крок 3: φ(n) = (61-1)(53-1) = 60 × 52 = 3120

Крок 4: Обираємо e = 17 (gcd(17, 3120) = 1) ✓

Крок 5: Знаходимо d: 17 × d ≡ 1 (mod 3120)
        d = 2753 (бо 17 × 2753 = 46801 = 15 × 3120 + 1)

Публічний ключ:  (3233, 17)
Приватний ключ:  (3233, 2753)
```

### Шифрування та дешифрування

```
┌─────────────────────────────────────────────────────────────────────┐
│                    ШИФРУВАННЯ RSA                                   │
│                                                                     │
│  Шифрування (публічним ключем):                                     │
│                                                                     │
│      C = Mᵉ mod n                                                   │
│                                                                     │
│  Дешифрування (приватним ключем):                                   │
│                                                                     │
│      M = Cᵈ mod n                                                   │
│                                                                     │
│  Чому це працює?                                                    │
│                                                                     │
│      Cᵈ = (Mᵉ)ᵈ = Mᵉᵈ mod n                                         │
│                                                                     │
│      За теоремою Ейлера: Mᵉᵈ ≡ M (mod n)                            │
│      (бо e×d ≡ 1 (mod φ(n)))                                        │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

**Приклад:**

```
Повідомлення M = 123
Публічний ключ: (n=3233, e=17)
Приватний ключ: (n=3233, d=2753)

Шифрування:
C = 123¹⁷ mod 3233 = 855

Дешифрування:
M = 855²⁷⁵³ mod 3233 = 123 ✓
```

### Алгоритм швидкого піднесення до степеня

Для великих показників використовують **бінарне піднесення** (square-and-multiply):

```cpp
#include <cstdint>

using u64 = unsigned long long;

// Швидке піднесення до степеня за модулем: base^exp mod modulus
// Метод "піднести до квадрата й помножити" — O(log exp) множень
u64 fastPower(u64 base, u64 exp, u64 modulus) {
    u64 result = 1;
    base %= modulus;

    while (exp > 0) {
        if (exp & 1ULL) {                  // непарний показник — множимо на base
            result = (result * base) % modulus;
        }
        exp >>= 1;                         // exp = exp / 2
        base = (base * base) % modulus;    // base = base^2
    }
    return result;
}

// Приклад: 123^17 mod 3233
// 17 = 10001 у двійковій системі
// 123^17 = 123^16 * 123^1 = ((123^8)^2) * 123
```

### Реалізація RSA мовою C++

```cpp
#include <iostream>
#include <random>
#include <stdexcept>

using u64 = unsigned long long;

u64 fastPower(u64 base, u64 exp, u64 modulus);   // з попереднього прикладу

// Тест простоти Міллера-Рабіна: ймовірнісний, але за 10 раундів
// похибка менша за 4^-10
bool isPrime(u64 n, int rounds = 10) {
    if (n < 2) return false;
    if (n == 2 || n == 3) return true;
    if (n % 2 == 0) return false;

    u64 d = n - 1;
    int r = 0;
    while (d % 2 == 0) { d /= 2; ++r; }    // n - 1 = 2^r * d

    std::random_device rd;
    std::mt19937_64 gen(rd());
    std::uniform_int_distribution<u64> dist(2, n - 2);

    for (int i = 0; i < rounds; ++i) {
        u64 x = fastPower(dist(gen), d, n);
        if (x == 1 || x == n - 1) continue;

        bool composite = true;
        for (int j = 0; j < r - 1; ++j) {
            x = fastPower(x, 2, n);
            if (x == n - 1) { composite = false; break; }
        }
        if (composite) return false;
    }
    return true;
}

// Випадкове просте число заданої розрядності
u64 generatePrime(int bits) {
    std::random_device rd;
    std::mt19937_64 gen(rd());
    std::uniform_int_distribution<u64> dist(1ULL << (bits - 1), (1ULL << bits) - 1);

    while (true) {
        u64 candidate = dist(gen) | 1ULL;   // число має бути непарним
        if (isPrime(candidate)) return candidate;
    }
}

// Обернений елемент e^-1 mod phi, розширений алгоритм Евкліда
u64 modInverse(u64 e, u64 phi) {
    long long oldR = static_cast<long long>(e), r = static_cast<long long>(phi);
    long long oldS = 1, s = 0;

    while (r != 0) {
        long long q = oldR / r;
        long long tmp = oldR - q * r;  oldR = r;  r = tmp;
        tmp = oldS - q * s;            oldS = s;  s = tmp;
    }

    if (oldR != 1) throw std::runtime_error("Оберненого елемента не існує");

    long long mod = static_cast<long long>(phi);
    return static_cast<u64>(((oldS % mod) + mod) % mod);
}

class RSA {
public:
    RSA(u64 p, u64 q) {
        n_ = p * q;
        u64 phi = (p - 1) * (q - 1);

        e_ = 65537;
        if (e_ >= phi) e_ = 17;                        // для малих навчальних ключів
        while (gcd(e_, phi) != 1) e_ += 2;

        d_ = modInverse(e_, phi);
    }

    u64 encrypt(u64 message) const { return fastPower(message, e_, n_); }
    u64 decrypt(u64 cipher) const  { return fastPower(cipher, d_, n_); }

    u64 modulus() const { return n_; }
    u64 e() const { return e_; }
    u64 d() const { return d_; }

private:
    static u64 gcd(u64 a, u64 b) {
        while (b != 0) { u64 t = a % b; a = b; b = t; }
        return a;
    }

    u64 n_ = 0, e_ = 0, d_ = 0;
};

int main() {
    RSA rsa(61, 53);

    std::cout << "n = " << rsa.modulus() << ", e = " << rsa.e() << ", d = " << rsa.d() << "\n";

    u64 message = 65;
    u64 cipher = rsa.encrypt(message);
    std::cout << "M = " << message << " → C = " << cipher
              << " → M' = " << rsa.decrypt(cipher) << "\n";
    return 0;
}
```

### Безпека RSA

**Рекомендовані розміри ключів:**

| Рік | Мінімум | Рекомендовано |
|-----|---------|---------------|
| 2020 | 2048 біт | 3072 біт |
| 2030+ | 3072 біт | 4096 біт |

**Атаки на RSA:**

1. **Факторизація n** — найпряміша атака
2. **Малий публічний показник** — якщо e мале і M мале, C = Mᵉ може не "обернутися" за модулем
3. **Спільний модуль** — не використовуйте один n для різних користувачів
4. **Timing attacks** — час дешифрування видає інформацію про d

## Криптосистема Ель-Гамаля

### Математична основа

Ель-Гамаль (Taher Elgamal, 1985) базується на складності **дискретного логарифму**:

```
Легко:   y = gˣ mod p    (піднесення до степеня)

Важко:   x = log_g(y) mod p    (дискретний логарифм)
         Знайти x, знаючи y, g, p
```

### Генерація ключів

```
┌─────────────────────────────────────────────────────────────────────┐
│                    ГЕНЕРАЦІЯ КЛЮЧІВ ЕЛЬ-ГАМАЛЯ                      │
│                                                                     │
│  Крок 1: Обираємо велике просте p та генератор g групи Z*_p         │
│          (g — примітивний корінь за модулем p)                      │
│                                                                     │
│  Крок 2: Обираємо випадкове x, де 1 < x < p-1                       │
│          (приватний ключ)                                           │
│                                                                     │
│  Крок 3: Обчислюємо y = gˣ mod p                                    │
│          (публічний ключ)                                           │
│                                                                     │
│  Результат:                                                         │
│  • Публічний ключ:  (p, g, y)                                       │
│  • Приватний ключ:  x                                               │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

### Шифрування

```
┌─────────────────────────────────────────────────────────────────────┐
│                    ШИФРУВАННЯ ЕЛЬ-ГАМАЛЯ                            │
│                                                                     │
│  Вхід: повідомлення M (число < p)                                   │
│                                                                     │
│  Крок 1: Обираємо випадкове k, де 1 < k < p-1                       │
│          (сесійний ключ, новий для кожного повідомлення!)           │
│                                                                     │
│  Крок 2: Обчислюємо:                                                │
│          a = gᵏ mod p                                               │
│          b = M × yᵏ mod p                                           │
│                                                                     │
│  Шифротекст: (a, b)                                                 │
│                                                                     │
│  Зверніть увагу: шифротекст удвічі більший за відкритий текст!      │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

### Дешифрування

```
┌─────────────────────────────────────────────────────────────────────┐
│                    ДЕШИФРУВАННЯ ЕЛЬ-ГАМАЛЯ                          │
│                                                                     │
│  Вхід: шифротекст (a, b)                                            │
│                                                                     │
│  Обчислюємо:                                                        │
│          M = b × a⁻ˣ mod p                                          │
│            = b × (aˣ)⁻¹ mod p                                       │
│                                                                     │
│  Чому це працює?                                                    │
│                                                                     │
│          b × a⁻ˣ = (M × yᵏ) × (gᵏ)⁻ˣ                                │
│                  = M × (gˣ)ᵏ × g⁻ᵏˣ                                 │
│                  = M × gᵏˣ × g⁻ᵏˣ                                   │
│                  = M                                                │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

### Приклад

```
Параметри: p = 23, g = 5

Генерація ключів:
  x = 6 (приватний)
  y = 5⁶ mod 23 = 15625 mod 23 = 8 (публічний)

Публічний ключ: (23, 5, 8)
Приватний ключ: 6

Шифрування M = 7:
  k = 3 (випадковий)
  a = 5³ mod 23 = 125 mod 23 = 10
  b = 7 × 8³ mod 23 = 7 × 512 mod 23 = 3584 mod 23 = 17

Шифротекст: (10, 17)

Дешифрування:
  a⁻ˣ = 10⁻⁶ mod 23
  aˣ = 10⁶ mod 23 = 1000000 mod 23 = 16
  (aˣ)⁻¹ mod 23: 16 × ? ≡ 1 (mod 23) → 16 × 13 = 208 = 9×23 + 1, отже 13

  M = 17 × 13 mod 23 = 221 mod 23 = 7 ✓
```

### Реалізація Ель-Гамаля

```cpp
#include <iostream>
#include <random>
#include <utility>

using u64 = unsigned long long;

u64 fastPower(u64 base, u64 exp, u64 modulus);   // див. вище

// Криптосистема Ель-Гамаля будується на складності дискретного логарифма
class ElGamal {
public:
    ElGamal(u64 p, u64 g) : p_(p), g_(g) {
        std::random_device rd;
        std::mt19937_64 gen(rd());
        std::uniform_int_distribution<u64> dist(2, p_ - 2);

        x_ = dist(gen);                  // закритий ключ
        y_ = fastPower(g_, x_, p_);      // відкритий ключ y = g^x mod p
    }

    // Зашифрування дає пару (a, b); для кожного повідомлення
    // береться новий випадковий сеансовий ключ k
    std::pair<u64, u64> encrypt(u64 message) const {
        std::random_device rd;
        std::mt19937_64 gen(rd());
        std::uniform_int_distribution<u64> dist(2, p_ - 2);

        u64 k = dist(gen);
        u64 a = fastPower(g_, k, p_);
        u64 b = (message % p_) * fastPower(y_, k, p_) % p_;
        return { a, b };
    }

    // Розшифрування: m = b * (a^x)^-1 mod p,
    // обернений елемент знаходимо за малою теоремою Ферма
    u64 decrypt(u64 a, u64 b) const {
        u64 s = fastPower(a, x_, p_);
        u64 sInv = fastPower(s, p_ - 2, p_);
        return (b * sInv) % p_;
    }

    void printPublicKey() const {
        std::cout << "Відкритий ключ: (p=" << p_ << ", g=" << g_ << ", y=" << y_ << ")\n";
    }

private:
    u64 p_, g_, x_, y_;
};

int main() {
    ElGamal elgamal(467, 2);            // малі числа для демонстрації
    elgamal.printPublicKey();

    u64 message = 123;
    std::pair<u64, u64> cipher = elgamal.encrypt(message);

    std::cout << "Шифротекст:   (" << cipher.first << ", " << cipher.second << ")\n";
    std::cout << "Розшифровано: " << elgamal.decrypt(cipher.first, cipher.second) << "\n";
    return 0;
}
```

## 📋 Cheat Sheet

### Ключові алгоритми RSA

```
┌─────────────────────────────────────────────────────────────────────┐
│                    RSA CHEAT SHEET                                  │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│  ГЕНЕРАЦІЯ КЛЮЧІВ:                                                  │
│  1. p, q — великі прості числа (1024+ біт кожне)                    │
│  2. n = p × q                                                       │
│  3. φ(n) = (p-1)(q-1)                                               │
│  4. e = 65537 (стандартна публічна експонента)                      │
│  5. d = e⁻¹ mod φ(n)                                                │
│                                                                     │
│  ШИФРУВАННЯ:   C = Mᵉ mod n                                         │
│  ДЕШИФРУВАННЯ: M = Cᵈ mod n                                         │
│  ПІДПИС:       S = H(M)ᵈ mod n                                      │
│  ПЕРЕВІРКА:    H(M) == Sᵉ mod n                                     │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

### OpenSSL команди

```bash
# Генерація RSA ключа
openssl genrsa -out private.pem 2048

# Витяг публічного ключа
openssl rsa -in private.pem -pubout -out public.pem

# Перегляд параметрів ключа
openssl rsa -in private.pem -text -noout

# Шифрування файлу публічним ключем
openssl rsautl -encrypt -pubin -inkey public.pem -in plaintext.txt -out encrypted.bin

# Дешифрування приватним ключем
openssl rsautl -decrypt -inkey private.pem -in encrypted.bin -out decrypted.txt

# Підпис файлу
openssl dgst -sha256 -sign private.pem -out signature.bin document.txt

# Перевірка підпису
openssl dgst -sha256 -verify public.pem -signature signature.bin document.txt

# Генерація RSA-4096 для продакшену
openssl genrsa -out private_4096.pem 4096
```

### Готові бібліотеки: OpenSSL

```cpp
// У промислових застосунках власну реалізацію RSA не пишуть:
// беруть перевірену бібліотеку. Для C++ це, наприклад, OpenSSL.
// Нижче — шифрування з доповненням OAEP (RSA без доповнення небезпечний).
#include <openssl/evp.h>
#include <openssl/rsa.h>
#include <vector>
#include <string>

std::vector<unsigned char> rsaEncrypt(EVP_PKEY* publicKey, const std::string& message) {
    EVP_PKEY_CTX* ctx = EVP_PKEY_CTX_new(publicKey, nullptr);
    EVP_PKEY_encrypt_init(ctx);

    // Доповнення OAEP з хешуванням SHA-256
    EVP_PKEY_CTX_set_rsa_padding(ctx, RSA_PKCS1_OAEP_PADDING);
    EVP_PKEY_CTX_set_rsa_oaep_md(ctx, EVP_sha256());

    size_t outLen = 0;
    EVP_PKEY_encrypt(ctx, nullptr, &outLen,
                     reinterpret_cast<const unsigned char*>(message.data()), message.size());

    std::vector<unsigned char> ciphertext(outLen);
    EVP_PKEY_encrypt(ctx, ciphertext.data(), &outLen,
                     reinterpret_cast<const unsigned char*>(message.data()), message.size());
    ciphertext.resize(outLen);

    EVP_PKEY_CTX_free(ctx);
    return ciphertext;
}

// Ключ генерують окремо: EVP_RSA_gen(2048) або утилітою
// openssl genpkey -algorithm RSA -pkeyopt rsa_keygen_bits:2048
```

### Завдання: Станьте криптографом — згенеруйте RSA ключі та підпишіть документ

Створіть власну пару RSA ключів та підпишіть файл — саме так працює електронний підпис у реальному світі!

**Кроки:**

1. Згенеруйте RSA ключі через OpenSSL:
```bash

# Витягніть публічний ключ
openssl rsa -in my_private.pem -pubout -out my_public.pem

# Перегляньте параметри ключа
openssl rsa -in my_private.pem -text -noout | head -20
```

2. Підпишіть файл:
```bash
# Створіть документ
echo "Я, $(whoami), підтверджую цей документ. Дата: $(date)" > document.txt

# Підпишіть його
openssl dgst -sha256 -sign my_private.pem -out document.sig document.txt

# Перевірте підпис
openssl dgst -sha256 -verify my_public.pem -signature document.sig document.txt
```

3. Спробуйте зламати:
```bash

echo "HACKED" >> document.txt

# Перевірте підпис знову — має бути помилка!
openssl dgst -sha256 -verify my_public.pem -signature document.sig document.txt
```

**Очікуваний результат:**
- Пара ключів: `my_private.pem` та `my_public.pem`
- Підписаний документ з валідним підписом
- Розуміння, що змінений документ не проходить верифікацію

**Бонус (для допитливих):**
- Зашифруйте файл публічним ключем: `openssl rsautl -encrypt -pubin -inkey my_public.pem -in secret.txt -out secret.enc`
- Порівняйте час генерації RSA-2048 vs RSA-4096
- Спробуйте ECDSA: `openssl ecparam -genkey -name prime256v1 -out ecdsa.pem`

## Тест для самоперевірки

Десять запитань, у кожному одна правильна відповідь. Якщо тема винесена вашій групі на самостійне опрацювання, цей самий тест публікується в Google Classroom — 10 балів, по одному за кожне запитання.

**1.** На складності якої задачі тримається стійкість RSA?

- факторизації великого числа на два прості множники
- обчислення дискретного логарифма
- пошуку колізій хеш-функції
- перевірки числа на простоту

**2.** Як обчислюється функція Ейлера φ(n) під час генерації ключів RSA?

- (p − 1)(q − 1)
- p × q
- (p + 1)(q + 1)
- p × q − 1

**3.** Яку умову має задовольняти публічна експонента e?

- gcd(e, φ(n)) = 1
- e має ділити φ(n) без остачі
- e має бути взаємно простим з n
- e має бути більшим за n

**4.** Що є публічним ключем RSA?

- пара (n, e)
- пара (n, d)
- пара простих чисел (p, q)
- саме лише значення φ(n)

**5.** За якою формулою шифрують повідомлення в RSA?

- C = Mᵉ mod n
- C = Mᵈ mod n
- C = M × e mod n
- C = eᴹ mod n

**6.** Чому стандартним вибором для e є 65537?

- у двійковому записі має лише дві одиниці, тож піднесення до степеня швидке
- це найбільше просте число, менше за 2¹⁶
- воно взаємно просте з будь-яким φ(n)
- цього вимагає формат сертифіката X.509

**7.** Чим небезпечно взяти p і q близькими одне до одного?

- n ≈ p², і атака Ферма швидко знаходить множники
- φ(n) стає непарним, і d не існує
- шифротекст стає коротшим за повідомлення
- дешифрування перестає бути однозначним

**8.** На складності якої задачі тримається криптосистема Ель-Гамаля?

- дискретного логарифма
- факторизації великих чисел
- пошуку прообразу хешу
- задачі про рюкзак

**9.** Чому шифротекст Ель-Гамаля вдвічі довший за повідомлення?

- це пара (a, b), і кожна частина завдовжки з модуль p
- повідомлення шифрується двома різними ключами
- до шифротексту додається цифровий підпис
- сесійний ключ k передається разом із текстом

**10.** Що отримає зловмисник, якщо одне й те саме k використати для двох повідомлень?

- відношення відкритих текстів M₁/M₂ = b₁/b₂
- приватний ключ x у явному вигляді
- нічого: k можна повторювати
- два однакових шифротексти, які не розшифрувати

## Підсумок

| Термін | Визначення |
|--------|------------|
| **RSA** | Криптосистема на факторизації |
| **Ель-Гамаль** | Криптосистема на дискретному логарифмі |
| **φ(n)** | Функція Ейлера: кількість чисел < n, взаємно простих з n |
| **e, d** | Публічна та приватна експоненти RSA |
| **Сесійний ключ k** | Випадкове число в Ель-Гамаля |

**Ключові формули:**
- RSA шифрування: `C = Mᵉ mod n`
- RSA дешифрування: `M = Cᵈ mod n`
- Ель-Гамаль: `(a, b) = (gᵏ, M × yᵏ)`

На наступній лекції розглянемо електронний цифровий підпис та хеш-функції.
