## Теоретичний матеріал

### Симетричне шифрування

**Симетричне шифрування** — криптографічна система, в якій для шифрування та дешифрування використовується **один і той самий ключ**.

```
┌─────────────────────────────────────────────────────────────────────┐
│                    СИМЕТРИЧНА КРИПТОСИСТЕМА                         │
│                                                                     │
│   Аліса                    Секретний канал                    Боб  │
│     │                            │                              │   │
│     │◄──────────── Ключ K ──────►│◄────── Ключ K ──────────────►│   │
│     │                            │                              │   │
│     ▼                            │                              ▼   │
│  ┌──────┐     Шифротекст C      │                          ┌──────┐│
│  │  E   │──────────────────────►│─────────────────────────►│  D   ││
│  │(P,K) │                        │      Відкритий канал     │(C,K) ││
│  └──────┘                        │                          └──────┘│
│     ▲                                                          │    │
│     │                                                          ▼    │
│  Plaintext P                                            Plaintext P │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

### Проблема розподілу ключів

Головна проблема симетричного шифрування — **як безпечно передати ключ?**

Якщо є захищений канал для передачі ключа, навіщо тоді шифрування?

**Історичні рішення:**
- Кур'єри з дипломатичною поштою
- Попередній обмін ключами при особистій зустрічі
- Книжкові шифри (ключ — сторінка книги)

**Сучасні рішення:**
- Протокол Діффі-Геллмана (1976)
- Гібридні системи (RSA + AES)

### Мережа Фейстеля

**Мережа Фейстеля** (Horst Feistel, IBM, 1973) — архітектура блочного шифру, де блок ділиться на дві половини.

```
       Вхідний блок (2n біт)
    ┌──────────┬──────────┐
    │    L₀    │    R₀    │
    └────┬─────┴────┬─────┘
         │          │
    ┌────┴────┐     │
    │         │◄────┴─────── K₁ (ключ раунду)
    │    F    │
    │         │
    └────┬────┘
         │
    ┌────⊕────┐     │
    │         │◄────┘
    └────┬────┘
         │
         └────────┬─────────┐
                  │    ↓    │
    ┌─────────────┴────┬────┴─────┐
    │    L₁ = R₀       │  R₁ = L₀ ⊕ F(R₀, K₁)
    └──────────────────┴──────────┘
         │                   │
        ...                 ...  (повторюємо n раундів)
```

**Властивості:**
1. **Оборотність**: дешифрування — ті ж операції у зворотному порядку
2. **Функція F може бути будь-якою**: не обов'язково оборотною
3. **Простота реалізації**: однаковий код для шифрування/дешифрування

**Шифри на основі мережі Фейстеля:**
- DES
- Blowfish
- Twofish
- GOST 28147-89

### SP-мережі (Substitution-Permutation Networks)

**SP-мережа** — альтернативна архітектура, де весь блок обробляється одночасно.

```
       Вхідний блок (128 біт)
    ┌──────────────────────────┐
    │                          │
    └────────────┬─────────────┘
                 │
                 ⊕ ◄─────────────── Ключ раунду K₁
                 │
    ┌────────────┴─────────────┐
    │     S-блоки (Substitution)│   ← Нелінійна заміна
    │  ┌───┐ ┌───┐ ┌───┐ ┌───┐ │
    │  │ S │ │ S │ │ S │ │ S │ │
    │  └───┘ └───┘ └───┘ └───┘ │
    └────────────┬─────────────┘
                 │
    ┌────────────┴─────────────┐
    │     P-шар (Permutation)   │   ← Перемішування бітів
    └────────────┬─────────────┘
                 │
                ...              (повторюємо n раундів)
                 │
    ┌────────────┴─────────────┐
    │      Вихідний блок        │
    └──────────────────────────┘
```

**Компоненти:**
- **S-блок (Substitution box)**: нелінійна заміна, забезпечує конфузію
- **P-шар (Permutation layer)**: перемішування бітів, забезпечує дифузію

**Шифри на основі SP-мереж:**
- AES
- Serpent
- PRESENT

### Конфузія та дифузія

Клод Шеннон (1949) сформулював два принципи стійкого шифру:

**Конфузія** — зв'язок між ключем та шифротекстом має бути складним.
- Досягається S-блоками (нелінійна заміна)
- Зміна одного біта ключа → зміна багатьох бітів шифротексту

**Дифузія** — зміна одного біта відкритого тексту → зміна багатьох бітів шифротексту.
- Досягається перестановками та змішуванням
- "Розмиває" статистичні властивості

```
      Конфузія                    Дифузія
    (Ключ → Шифр)            (Текст → Шифр)

    K: 10110...              P: 10110...
        ↓                        ↓
    Складний                 Один біт змінено
    зв'язок                      ↓
        ↓                    P: 10111...
    C: ?????                     ↓
                             C: повністю інший!
```

### Лавинний ефект

**Лавинний ефект** (Avalanche effect) — зміна одного біта входу повинна змінювати приблизно 50% бітів виходу.

```python
# Демонстрація лавинного ефекту в AES
from Crypto.Cipher import AES

key = b'0123456789ABCDEF'
cipher = AES.new(key, AES.MODE_ECB)

# Два тексти, що відрізняються на 1 біт
text1 = b'AAAAAAAAAAAAAAAA'
text2 = b'AAAAAAAAAAAAAAAB'  # Останній біт змінено

enc1 = cipher.encrypt(text1)
enc2 = cipher.encrypt(text2)

# Порівнюємо кількість різних бітів
diff_bits = bin(int.from_bytes(enc1, 'big') ^
                int.from_bytes(enc2, 'big')).count('1')
print(f"Різних бітів: {diff_bits} з 128 ({diff_bits/128*100:.1f}%)")
```
